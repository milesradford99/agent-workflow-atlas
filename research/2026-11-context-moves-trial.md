# 试写：每条的“一招”与上下文工程分类（2026-11-15）

目的：检验“条目开头先写它与默认做法（AI 起草、人审阅）差在哪”能否解决“千篇一律”的问题。这是一份试写记录，没有改任何条目或标准。

方法：5 个界各随机抽 4 条（固定随机种子 27），只读每条的 summary、shape、“失败模式 → 防护”和“与相近工作流的区别”四行，没有通读全文。“一招”和分类是我的判断，数字都出自条目原文。

## 分类（暂定 5 类 + 标准形态）

| 代号 | 上下文工程动作 | 含义 |
|---|---|---|
| 放入 | 先备好的输入 | 开工前由人确认的术语表、标签指南、参考图，模型照它做 |
| 挡住 | 提示词之外的限制 | 白名单、只读权限、只许已知安全动作；不靠模型自觉 |
| 外验 | 模型之外的验证 | 构建、规则检查、回查、实验重复；结果由程序或现实判定 |
| 回灌 | 把纠正写回去 | 人的修改进入技能文件、提示词或文档，下一轮生效 |
| 分流 | 按把握和风险决定谁看 | 置信度、风险或归属决定送给哪个人，还是不送 |
| 标准 | 无 | 就是“AI 起草、人审阅/接手”加行业背景 |

## 20 条试写

| 条目 | 分类 | 一招 |
|---|---|---|
| AWF-0069 筛选式测试补充 | 外验 | 不评判生成的测试好坏，让它依次过构建、通过、5 次重跑、覆盖率提升四道筛；只有约 4–5% 存活，所以多跑便宜的尝试，每个存活测试单独一个 diff。 |
| AWF-0004 先分诊再修复 | 标准 | 调查、排序假设、人批准每条 runbook 命令。条目没有防护一行。 |
| AWF-0194 用智能体评测文档 | 回灌 | 智能体不是写文档的，是文档的考生：让几个智能体照文档搭界面，失败处由维护者翻译成文档修改。让智能体自己按反馈改文档会失控，作者试过。 |
| AWF-0189 先自修再转人工 | 挡住 | 只允许已知的安全修复动作；用故意弄坏的测试虚拟机做评测，按每个系统版本测。 |
| AWF-0042 导师批准的 AI 回复 | 标准 | 每条消息都由导师批准。亮点是数字而不是做法：3,617 条草稿里 5 条事实错误。 |
| AWF-0102 带护栏的课程答疑 | 回灌 | 提示词越长模型越不听（换模型后带代码块的回复从 20% 升到 25%）；改提示词前由助教对新旧回答做成对比较。 |
| AWF-0034 化学家把关的 DMTA 循环 | 外验 | 微量实验的结果不算数，化学家在台面规模重做一遍才算签发。 |
| AWF-0155 核保人审阅的报价 | 标准 | 限定险种、续保、地区后起草报价，核保人审阅。 |
| AWF-0054 带护栏的活动搭建 | 挡住 | 先上 URL 白名单和产品名词典再写文案；第一版没有它们，10.5% 渲染出错。 |
| AWF-0112 按置信度抽检的属性提取 | 分流 | 置信度由另一个验证模型给，不信模型自报；只有低分项和定期抽样到人手里。 |
| AWF-0114 供应商确认的目录修正 | 分流 | 有风险的修改交给外部供应商确认，而不是内部审核员。 |
| AWF-0019 广告变体矩阵 | 外验（弱） | 审阅前加一道宣称核查：投放回报好看但夸大的脚本，后面会换来退货和差评。 |
| AWF-0140 图生 3D 资产包 | 放入 | 留用率取决于输入：先画没有透视变形的多视图概念图，再生成。 |
| AWF-0136 术语把关的游戏本地化 | 放入 + 外验 | 每个版本先挖术语、由语言专家确认，再翻译；规则层拦住 70% 以上的格式和术语问题。 |
| AWF-0074 记者笔记改写台 | 标准 | 改写编辑审阅，记者最后通读。 |
| AWF-0135 发布周期文档技能 | 外验 + 回灌 | 发布说明对照变更文件核对，阶段标签对照 YAML 核对，截图由子智能体比对；审阅意见写回各产品的 SKILL 文件。 |
| AWF-0206 封闭式 HR 服务台 | 标准 | 回答、办理常规事务，敏感的转人工。 |
| AWF-0144 经理批准的招聘动作 | 外验 | 缺数据时必须标记而不是归档；写入三个系统后逐个回查再汇报，防止某个系统静默失败。 |
| AWF-0145 日历时间审计 | 标准 | 只读日历、给出建议，本人逐条取舍。 |
| AWF-0153 漏提货致电并决策 | 标准 | 打电话确认、决定下一步，解决不了的转人工。 |

## 结果

- 13 条能写出一招，其中 1 条偏弱（AWF-0019）。
- 7 条是标准形态（35%）：AWF-0004、0042、0155、0074、0206、0145、0153。
- 5 个分类够用，没有出现放不进去的条目；“外验”最多（7 条含并列），“放入”“挡住”各 2–3 条。

## 局限

- 样本 20 条，35% 只是粗估。
- 只读了四行，通读后有的“标准”条目可能找得出一招，有的“一招”可能站不住。
- “标准形态”里有的条目价值在数字或证据（如 AWF-0042），不在做法；它们需要另一种开头，不该简单折叠。
