# 声明监测事实核查台

**工具变体：** `full-fact-ai` · `synthid-detector` · `slack`

## 背景

事实核查机构或新闻编辑部的核查台，会把公共言论（比如政治人物引用的数据、一段流传很广的健康视频）拿去与证据对照，并发表文章。头一个难题是找出这些说法：它们散见于报纸、广播电视、社交媒体和议会辩论，远超一个小团队读得完、看得完的量。第二个难题是同一条错误说法会在新的地方再次出现，又被重复核查一遍。智能体每天读取受监测的材料，给说法打标签，评估哪些值得核查员花时间，并把重复出现的说法链接到以往的核查。选哪些来核查仍由人决定，因为这一选择决定机构对外说什么，而模型无法判断一条说法是真是假。每篇文章的调研、撰写和审校也都由人完成，因为发表的结论是以机构的名义发出的。

**术语：**
- **声明（claim）**：可以判断真假的陈述，例如被引用的某个统计数字，区别于意见。
- **值得核查度（checkworthiness）**：一条声明值得核查员花时间的可能性，例如它有害、传播广或可以查证。
- **声明匹配（claim matching）**：找出新出现的、与已核查过的声明表达同一说法的句子。
- **Hansard**：英国议会辩论的官方文字记录。
- **PMQs**：首相质询，每周一次的议会现场环节，议员向首相提问。
- **回应权（right of reply）**：发表前给声明背后的个人或机构一个回应的机会。
- **句子嵌入、实体识别、词性标注器**：三种文本分析方法，分别是把句子转成数字以便比较、找出人名和地名、标出每个词的语法角色。声明匹配需要它们，以免把涉及不同人或地点的声明混为一谈。
- **SynthID**：谷歌的水印，部分 AI 生成的图片和视频带有它，检测器可以读出。

## 用智能体搭建

**形态：** `service`。监测运行时没有人守在键盘前：它每天自行运行，人只看到早间摘要和匹配信息流。

**需要：** 受监测来源的文本形式的订阅源或导出文件（新闻、议会记录、文字稿），广播和视频需另用独立的语音转文字服务；一个放在对话之外的存储，保存近期的事实核查和以往运行的结果；一个聊天连接器（MCP 服务器），用来向团队频道发消息；对已发表事实核查的只读权限。智能体不需要任何写入发布系统的工具。

| 步骤 | 搭建方式 |
|---|---|
| 每个来源：转写 → 主题标注 | 云端定时任务或 `claude -p` 作业从存储中读取每条新内容。音频和视频先在智能体之外转写。智能体按一份固定清单给每条内容标注主题。 |
| 每个声明：判定声明类型 + 声明者 → 值得核查度评分 | 一个 skill 保存声明的定义、声明类型和评分标准；智能体给每条声明打标签并评分。量大时由子智能体分批处理。从不让它判断声明是否属实。 |
| 与近期事实核查匹配 | 同一次运行把每条声明与存储中的近期事实核查作比较，记录可能的匹配及所匹配核查的链接。 |
| 晨间主题摘要 + Slack 匹配信息流 | 运行结束时把最值得核查的声明按主题标题写成摘要，连同匹配结果通过聊天连接器发到团队频道。 |
| 🛑 review (决定是否核查) | 见检查点。 |
| 调研 + 来源统计数据 + 回应权 → 撰写事实核查 | 由核查员完成。在日常会话中，核查员可以让一个 skill 收集背景页面或查找某个统计数字的出处。 |
| 🛑 review (同事审校和编辑) → 发布 / 要求更正 | 见检查点。 |

**检查点：** `review`（第一次）：运行在发出摘要和匹配结果后结束；核查员查看被标记的片段，决定是否核查，在有人接手之前，这条声明不会有任何后续。`review`（第二次）：稿件由人撰写，在机构自己的发布系统中交给同事审校。智能体没有发布工具，也没有联系声明者的工具，所以漏掉一次停顿也不会到达公众或被核查的人。

**与来源相比：** 来源的时间从 2025-02 到 2026-06。它们描述的是一个机构多年自建的工具：训练过的分类器、训练过的匹配模型，以及 2026 年的水印扫描，而不是用通用部件拼起来的智能体。上面的搭建方式用通用模型加提示词取代了训练过的主题分类器和匹配模型，这一改动来源并未报道。它没有纳入 SynthID 扫描（需要单独的检测器），也没有纳入覆盖全部受监测媒体的搜索工具。它保留了来源的规则：从不让模型判断声明是否属实。视频和广播的转写仍需要智能体之外的语音转文字服务。Nieman Lab 的文章在 2026-11 无法打开，所以取自它的细节依据的是条目原文。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 监测工具持续摄入每日报纸、电视、广播、在线视频、社交媒体平台和 Hansard。现场活动（每周的首相质询、辩论）有实时文字稿。在 2026 年的选举期间，团队还监测了 1,000 多个与候选人相关的 Facebook、TikTok、X、YouTube 和 Instagram 账号，视频配有 AI 文字稿 [[1]](#sources)[[2]](#sources)。
2. 一个用 10,000 篇已标注文章训练的分类器，给每篇文章打上 17 个高层主题之一的标签。模型再给每条声明标注声明类型和声明者，并评出值得核查的程度。从不让模型判断声明是否属实 [[1]](#sources)。
3. 生成式 AI 对长视频和播客中的片段排序（例如健康方面的声明或情绪化的建议），让核查员可以直接跳到相关部分 [[1]](#sources)。
4. 声明匹配把所有受监测的媒体与近期已核查的声明作比较。句子嵌入借助实体识别和词性标注器得到增强，再加上一个训练过的匹配模型。匹配结果进入内部的 Slack 频道 [[1]](#sources)[[2]](#sources)。
5. 每天早上，系统把最值得核查的声明按主题标题展示。搜索工具可按发言人、政党或来源类型过滤 [[1]](#sources)。
6. 🛑 **审阅**：核查员观看或阅读被标记的部分以理解该声明，然后决定是否正式核查。由人来决定“什么值得关注” [[1]](#sources)[[2]](#sources)。
7. 核查员调研背景，找出统计类声明的出处，并在适当时给予回应权。AI 仅限于以图搜图之类的辅助手段，文章由核查员自己撰写 [[1]](#sources)。
8. 🛑 **审阅**：同事在发表前仔细审校并编辑文章 [[1]](#sources)。
9. 核查台发布事实核查。对于重复出现的声明，联系议员或请报社更正。选举期间还会增加对候选人图片和视频的 SynthID 水印扫描 [[1]](#sources)[[2]](#sources)。

**产出：** 已发布的事实核查和更正请求；给编辑团队的每日声明概览。
**失败模式 → 防护：** 声明匹配混淆了不同的人或地点 → 实体识别 + 词性标注器 + 训练过的匹配模型 [1]。数量压垮小团队 → 值得核查度排序 + Slack 信息流以降低摩擦 [2]。把 AI 当作真相神谕 → 从不让模型判断声明是否属实 [1]。
**与相近工作流的区别：** 最接近的是 AWF-0134（抽检式 LLM 记录分析，Sampled LLM records analysis）：那个智能体针对一篇调查报道，对一组文档回答固定的问题，由记者抽检答案。这里的产出是持续监测所得的一系列事实核查，每条浮现出的声明都由人来分诊。AWF-0074 把记者笔记改写成报道，输入和产出物都不同。

## 公开实例

覆盖度（截至 2026-11-13）：**充分**：有详细的第一手实例，与流程的大部分环节一致。收集与复核见 [Third collection pass](../../../../../research/2026-11-third-pass.md)。

- [Full Fact (Nowottny), Full Fact is battling AI-generated elections content](https://www.niemanlab.org/2026/06/full-fact-is-battling-ai-generated-elections-content-with-ai-tools-of-its-own/) (2026-06-25)。2026 年英国权力下放地区选举：监测候选人账号，把声明匹配到 Slack，水印扫描，人工分诊。"we scanned 16,514 images or videos attached to candidates' social media posts, and identified 136 that appeared to have watermarks"。*第一手：是；可信度：高。*
- [Full Fact (Corney), How AI can help fact checkers](https://fullfact.org/blog/2025/feb/how-ai-can-help-fact-checkers/) (2025-02-11)。从主题标注到声明匹配的完整流水线；该工具被其他事实核查机构使用。"used by over 40 fact checking organisations working in three languages across 30 countries on a daily basis"; "Over 200 fact check articles have been published about claims found there using our tools"。*第一手：是；可信度：高。*
