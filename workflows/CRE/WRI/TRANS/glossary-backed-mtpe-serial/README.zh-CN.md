# 术语库支撑的网文机翻后编

**与相近工作流的区别：** AWF-0012 每日网文连载写的是中文原创章节。AWF-0017 配音流水线本地化的是音视频，不是文字。
**工具变体：** `qidian-international-in-house`

## 步骤

1. 按各类型的风格建立多个文化类术语库（terminology glossaries），再为 AI 没学过的网络流行语建立专门的词表 [[1]](#sources)[[2]](#sources)。
2. 中文原文更新后不久，自动化流水线用大语言模型翻译每个新章节 [[1]](#sources)。
3. 🛑 **审阅**：人工译者以 MTPE 模式（AI+人工校对，即 AI 翻译加人工后编辑）工作。他们通读原文，然后修改、润色，有时重写译文，并核对成语、俚语和背景知识。最终的质量把关由人负责 [[1]](#sources)[[2]](#sources)。
4. 发布到起点国际（WebNovel）。收集读者评论用于关键词提取和数据分析，结果再反馈到译文和术语库中 [[1]](#sources)。

**产出：** 海外平台上的英文及其他语种连载章节，发布节奏与中文版保持接近。
**失败模式 → 防护：** 仙侠术语如炼气/筑基/元婴即使有术语库也被误译，俚语被直译，如破防 → 'break defense' → 类型术语库加强制的人工后编辑。经典仙侠和复杂人物关系的准确度低于都市或科幻类型 → 在这些类型上投入更多人力。
