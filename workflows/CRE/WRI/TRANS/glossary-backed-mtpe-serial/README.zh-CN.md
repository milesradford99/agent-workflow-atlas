# 术语库支撑的网文机翻后编

**工具变体：** `qidian-international-in-house`

## 背景

网文逐章发布，往往每天更新，追更的海外读者希望在中文版更新后很快就看到英文章节。靠人工翻译，跟不上成千上万部作品的更新速度。现在由一条流水线在中文原文更新后立即机器翻译每个新章节，并使用各类型的术语库，让人名和固定说法保持一致。机器译文在玄幻词汇、俚语和文化背景上仍会出错，所以每个章节上线前都由人工译者做后编辑，这个人对最终质量负责。已发布章节下的读者评论会被挖掘出来，用来修正并反馈到术语库。

**术语：**
- **网文**：为网络阅读平台创作、逐章发布的连载小说。
- **MTPE（机器翻译加后编辑）**：先由机器翻译，再由人工译者通读原文，对译文进行修改、润色，有时重写。来源把这一步称为校对，但它比校对要重。
- **术语库**：为某个类型维护的一份词表，列出原文术语及其认可的译法，让机器统一使用。
- **仙侠**：以修炼成仙为题材的中国玄幻小说；炼气、筑基、元婴这类境界名称没有通行的英文对应词。
- **破防**：网络流行语，原是游戏术语，指突破怪物的防御，如今指情绪失控；直译成 "break defense" 就丢了意思。
- **起点国际（WebNovel）**：网文出版方阅文集团的海外阅读平台。

## 用智能体搭建

**形态：** `service`。原文每次更新都要翻译，不会有人守在键盘前，人只看到一个待后编辑的草稿队列。

**需要：** 新的中文章节出现的订阅源或文件夹；作为智能体可读文件的各类型术语库和网络流行语词表；保存章节状态（已翻译、审阅中、已批准）的存储；供后编辑人员使用的审阅队列；导出或读取已发布章节读者评论的途径。智能体不接入发布平台。

| 步骤 | 搭建方式 |
|---|---|
| 建立类型术语库 (glossaries) | 由翻译团队维护的文件，每个类型一份，外加一份网络流行语词表，每次翻译运行都会加载。 |
| 新章节发布 → 自动机器翻译章节 | 一个云端定时任务，或由你自己的调度器运行的 `claude -p` 任务，接手每个新章节。一个 skill 给它术语库规则和输出格式；它把译文草稿写入存储。 |
| 🛑 review (人工校对：后编辑) | 见“检查点”。 |
| 发布到海外平台 | 由人或平台自带的工具发布批准后的文本。 |
| 挖掘读者评论 → 更新术语库 | 每周运行一次的定时任务读取导出的评论，把关于术语和人名的抱怨归类，并以文件形式提出术语库修改建议，由团队接受或拒绝。 |

**检查点：** `review`：每份草稿连同原文章节一起进入后编辑人员的队列，在后编辑人员标记为已批准之前，该章节保持未发布。智能体没有发布工具，所以未经审阅的章节到不了读者手里。术语库的修改建议同样等团队处理。

**与来源相比：** 来源出自 2025-01，另一个没有日期（来源 2 未标注日期）。两者讲的都是阅文海外平台用大语言模型做 MTPE，而不是智能体：流水线和术语库是该平台自己的工具，这套搭建方式是用通用智能体做的对等方案。较新的一篇记述，Rest of World 2026-07 的文章（[链接](https://restofworld.org/2026/china-ai-web-novels/)），报道该出版方已在 WebNovel 上发布超过 17,000 部 AI 翻译作品；它没有描述审阅这一步。截至 2026-11 的搜索没有找到关于术语库或后编辑流水线的更新的公开描述。来源称后编辑是必须的，而经典仙侠和复杂人物关系的准确度较弱；这套搭建方式让人对每一章都把关。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 翻译团队按各类型的风格建立多个文化类术语库（terminology glossaries），再为 AI 没学过的网络流行语建立专门的词表 [[1]](#sources)[[2]](#sources)。
2. 中文原文更新后不久，自动化流水线用大语言模型翻译每个新章节 [[1]](#sources)。
3. 🛑 **审阅**：人工译者以 MTPE 模式（机器翻译加后编辑，即 AI+人工校对）工作。他们通读原文，然后修改、润色，有时重写译文，并核对成语、俚语和背景知识。最终的质量把关由人负责 [[1]](#sources)[[2]](#sources)。
4. 平台把章节发布到起点国际（WebNovel）。收集读者评论用于关键词提取和数据分析，结果再反馈到译文和术语库中 [[1]](#sources)。

**产出：** 海外平台上的英文及其他语种连载章节，发布节奏与中文版保持接近。
**失败模式 → 防护：** 仙侠术语如炼气/筑基/元婴即使有术语库也被误译，俚语被直译，如破防 → 'break defense' → 类型术语库加强制的人工后编辑。经典仙侠和复杂人物关系的准确度低于都市或科幻类型 → 在这些类型上投入更多人力。
**与相近工作流的区别：** AWF-0012 每日网文连载写的是中文原创章节。AWF-0017 配音流水线本地化的是音视频，不是文字。
