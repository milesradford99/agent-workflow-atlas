# 分关把控的 AI 漫剧产线

**工具变体：** `jimeng-seedance` · `kling` · `volcengine`

## 背景

短剧是分集讲述的连续故事，每集一两分钟，在手机上观看，主要靠付费广告带来观众。漫剧是动画或漫画风格的短剧；AI 漫剧的画面和视频来自图像与视频生成模型，而不是实拍。工作室像产线一样制作它们：先决定做哪个故事，写剧本，把每个角色和场景一次设计定稿，使其在每个镜头里看起来一致，再规划镜头，每个镜头生成很多遍并留下最好的一条，最后剪辑并加上配音和字幕。画是模型画的。每个阶段由人来决定，因为发现得晚的错误意味着其后的一切都要重新生成，也因为工作室要对所发布内容的版权和肖像负责。

**术语：**
- **立项评审**：在花任何制作费用之前，决定一部剧做还是不做。
- **钩子**：开头的几秒钟，必须让观众停下来而不是划走。
- **数字资产**：每个角色、场景、服装和道具经审批的参考图，在每个镜头中复用，以保持一致。
- **分镜**：一集内容逐个镜头的计划。
- **文生图 / 图生视频**：由文字生成图像，由图像生成视频。
- **抽卡**：为一个镜头生成许多候选并留下最好的，说法来自游戏里的抽卡。
- **合规审核**：发布前对版权、肖像和平台规则的检查。
- **投放**：购买广告把观众引到剧上；结果显示哪些剧能收回成本。
- **ROI**：投资回报，这里指一部剧带来的收入与其制作和广告成本之比。

## 用智能体搭建

**形态：** `platform`。镜头由图像和视频生成模型制作，通用智能体替代不了；而且在两个来源里，每个阶段都是由人来做的。通用智能体可以以 `project` 的形态承担文字和协调类的阶段：用 skill 做评审清单和分镜，生成平台有 API 的话通过 API 调用。

**需要：** 图像和视频生成平台的账号；以文件形式保存、智能体可读的剧本、资产清单和分镜；原著以及任何真人肖像的授权文件；如果要让智能体汇总投放结果，还需要投放数据的导出文件。

| 步骤 | 搭建方式 |
|---|---|
| 立项评审 → 🛑 plan | 一个 skill 根据提案和给它的数据填写立项清单（钩子、竞争、受众匹配、版权、AI 可行性、ROI）。由人决定。 |
| 剧本 → 🛑 review | 写剧本是另一个工作流：[AWF-0014 Hook-cadence drama script](../../../WRI/SCREEN/hook-cadence-drama-script/)。 |
| 剧本拆解 + 数字资产 → 🛑 review | 智能体从剧本中列出每个角色、场景、服装和道具，并为每一项写一份参考说明。图像在生成平台上制作。 |
| 分镜 → 🛑 review | 智能体把分镜起草成一张表：镜头、景别、用到的资产、生成提示词。 |
| 每个镜头：抽卡 → 🛑 review | 生成平台。平台有 API 时，可以用脚本提交批量任务。由人挑选。 |
| 剪辑、配音、字幕、音效 → 🛑 review | 剪辑和音频工具。智能体可以根据剧本准备字幕文本。 |
| 🛑 sign-off (合规审核) | 智能体整理审核人需要的材料：每项资产的来源、已取得的授权、是否涉及真人肖像、AI 标识。由人签字。 |
| 投放测试 → 放大优胜作品 | 广告投放平台。智能体可以把结果的导出文件汇总，供下一次立项评审使用。 |

**检查点：** `plan`：立项 skill 给出填好的清单后停下。`review`：每个 skill 在交出草稿（剧本、资产说明、分镜）后停下；生成的片段和成片在生成与剪辑工具里审看，不经过智能体。`sign-off`：智能体没有发布或购买广告的工具；由人发布这部剧。

**与来源相比：** 来源描述的是由人组成的团队（例如一名导演带四名图像生成员）在使用生成工具。两个来源都没有提到由智能体来运转整条产线。因此本条目记录的是一个把 AI 模型当作工具的制作流程，上面的搭建方式只是针对其中文字类阶段的方案。由自动评审逐个检查镜头的产线是另一个条目：[AWF-0015 AI shot factory](../../AIGCVIDEO/ai-shot-factory/)。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 🛑 **计划**：工作室举行立项评审，考察多项因素：开场钩子、题材的拥挤程度、受众匹配、版权、AI 能否渲染这些场景，以及预期 ROI [[1]](#sources)。
2. 🛑 **审阅**：制片人从编剧手中接过剧本，剧本必须通过评审，才能交给 AI 美术团队 [[1]](#sources)。
3. 团队先拆解剧本，并搭建完整的数字资产库。一部剧通常会锁定 60–70 个角色造型，外加场景、服装和道具风格，资产必须通过评审，分镜才能发出 [[2]](#sources)。
4. 🛑 **审阅**：分镜要经过评审 [[1]](#sources)。然后由一名导演加四名图像生成员组成的小组，对每个镜头批量运行文生图和图生视频抽卡（生成并挑选）[[2]](#sources)。
5. 🛑 **审阅**：导演审看所有生成的片段，随后进行剪辑、配音、配乐和字幕 [[2]](#sources)。成片要经过两轮评审 [[1]](#sources)。
6. 🛑 **签发**：这部剧通过针对版权和肖像的合规审核，然后移交发行和付费投放测试，测试结果再反馈到剧本和视觉风格 [[1]](#sources)。

**产出：** 交付给短剧平台（如红果）的漫剧系列，其投放数据为下一轮立项决策提供依据。
**失败模式 → 防护：** 照搬 AI 渲染不了的实拍镜头语法；资产在镜头之间走样 → 立项时做 AI 可行性检查，任何镜头开拍前先做资产审批。无人检查的全自动输出 → 三轮评审（剧本、分镜、成片）。
**与相近工作流的区别：** AWF-0016 实拍辅助是用真人演员拍摄。AWF-0015 AI 镜头工厂（AIGCVIDEO）对每个镜头运行自动关键帧评审，一道审阅、一道签发。本产线是有分工的角色团队（导演加抽卡生成员），带数据驱动的立项、资产库审批关卡，以及三轮评审加合规。检查点安排和团队结构都不同。它是两个具名团队说法的综合，因此应视为中等可信度。
