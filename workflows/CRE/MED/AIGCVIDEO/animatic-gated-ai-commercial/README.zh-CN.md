# 动态分镜把关的 AI 广告片

**工具变体：** `claude-seedance-elevenlabs-remotion` · `nano-banana-kling-veo-premiere`

## 背景

广告片是为推销某一产品而拍的短片，通常 15 到 60 秒。客户（品牌方）出钱，并对片中所说的内容负责。通常是广告公司写简报、做创意概念、规划镜头、拍摄再剪辑。这里的画面和片段来自图像与视频生成模型，每个片段生成一次都要花钱，而且只有一部分能用。最贵的错误，是给后来被剪掉或改掉的镜头生成了视频，所以这项工作在生成任何视频之前，先把方案、分镜表和一版用静图搭成、带时间的粗剪定下来，并按批次批准支出。智能体写简报、概念和分镜表，让几个评审角色对分镜表挑错，并合成成片。每一道关由人来批准，因为信息和预算归客户所有，成片里的说法和观感由品牌方负责。

**术语：**
- **简报（brief）**：一页纸，写明产品、受众、广告必须说的一件事、调性和行动号召。
- **CTA**：行动号召，告诉观众下一步做什么的那句话。
- **节拍脚本**：把广告写成带时间的节拍（钩子、问题、演示、证明、CTA），旁白按真实语速排布。
- **钩子**：开头的几秒钟，必须让观众停下来而不是划走。
- **分镜表（shot list）**：整支片子逐个镜头的计划，这里每个镜头一个主体、一个动作、一次运镜。
- **关键帧 / 分镜图**：一个镜头起始的静止画面；每个镜头一张，合起来就是分镜图。
- **动态分镜（animatic）**：用静图和录好的配音搭出的粗剪，时长与成片一致。批准它就等于锁定剪辑。
- **风格配方**：对光线、镜头、色板和调色的固定描述，贴进每个图像和视频提示词，让各镜头风格一致。
- **视觉评判（vision judge）**：一个图像理解模型，对照分镜表和风格配方给每个生成的片段打分。
- **开头钩子变体与剪短版**：不同的开场几秒，以及用同一批素材剪出的更短或竖屏的版本（6 秒、15 秒）。
- **标签漂移**：产品的标签或包装在各条之间变了样子。

## 用智能体搭建

**形态：** `platform`。关键帧和片段来自图像与视频生成模型，通用智能体替代不了。通用智能体可以以 `project` 的形态承担其余所有步骤：用 skill 做简报、节拍脚本和分镜表，用子智能体做评审小组和视觉评判，再用一个钩子拦下任何未经批准的付费生成调用。

**需要：** 以文件形式保存的产品说明和真实产品照片；工作室所用图像、视频和配音生成服务的账号和 API 密钥；写在智能体可读位置的项目预算上限；存放关键帧、片段和动态分镜的文件夹；客户针对该产品类别的合规护栏。

| 步骤 | 搭建方式 |
|---|---|
| 简报 → 🛑 plan (简报) | 一个 skill 根据产品说明填写一张卡片式简报，然后停下。 |
| 三个创意概念 → 选定 + 带时间的节拍脚本 | skill 起草三个不同的概念并停下来等人选定；随后写出节拍脚本和备选的开场钩子。 |
| 分镜表 → (评审小组 ⟲ 导演修改) → 🛑 plan (分镜表) | skill 起草分镜表。三个只读子智能体（摄影指导、剪辑师、观众）各自返回意见；主对话据此修改并记录改动。一个脚本检查“一个主体、一个动作、一次运镜”的规则。 |
| 风格配方 + 产品参考图 → 分镜关键帧 | 一份参考文件保存风格配方，由 skill 贴进每个提示词。一个脚本为每个镜头向图像服务提交一张关键帧，并附上产品照片作为参考。 |
| 配音录制 → 按配音定时的动态分镜 → 🛑 review | 一个脚本请求配音并测量时长；skill 把关键帧按这些时长列出。动态分镜在智能体之外的剪辑工具里搭出。 |
| 成本估算 → 🛑 action (批准视频预算) | skill 把分批的视频任务按预算上限合计，然后停下。见“检查点”。 |
| 每个镜头：生成片段 → 视觉评判 → (分批重新生成 ⟲ 🛑 action) | 脚本只提交已批准的任务到视频服务。一个子智能体对照分镜表和风格配方给每个片段打分，返回通过或一句话的纠正方案；纠正方案作为新任务排队，等待批准。 |
| 配音 + 配乐 + 字幕 → 成片 + 开头钩子变体 + 剪短版 | 剪辑或渲染工具，不经过智能体。skill 写出剪辑清单和字幕文本。 |
| 🛑 sign-off (品牌审阅) | 品牌方的人。见“检查点”。 |

**检查点：** `plan`：skill 在简报之后、修改后的分镜表之后各停一次，每份文件经人批准才继续。`review`：skill 列出动态分镜的时长和镜头后停下；批准动态分镜就锁定剪辑和生成计划。`action`：视频生成要花钱，所以智能体不直接持有视频服务的密钥。一个 `PreToolUse` 钩子会拦下提交脚本，除非该任务在人写下的已批准清单上；每次重新生成都是新任务，需要同样的批准。`sign-off`：智能体没有上传或发布的工具，品牌方在自己的渠道里审阅主片。

**与来源相比：** 来源出自 2025-12 至 2026-08。它们描述的是个人从业者和一个企业内部团队借助生成工具运行这些关卡；文中称为“智能体”的角色（创意总监、拆解、评审）如今可以由一个 skill 和子智能体来担任。上面的搭建方式保留了来源报告的花钱关卡，略去了它们所用的具体工具，这些工具列在 `variants` 中。来源 1 在本次会话中无法打开（网站拒绝了请求），所以它的步骤取自条目正文。这套搭建方式没有被运行过；报道的实例用的是手工搭建的环境。

## 步骤

*以下按来源所述。*

1. 智能体把产品描述整理成一张卡片式简报（产品事实、受众、一个价值主张、调性、CTA、合规护栏）。🛑 **计划**：人先批准简报，之后才运行其他步骤 [[1]](#sources)。企业内部的品牌实践把简报压缩到一页、一句主线，并在第二天完成概念批准 [[2]](#sources)。
2. 创意总监智能体提出三个不同的概念；人选定一个，智能体写出带时间的节拍脚本（钩子、问题、演示、证明、CTA），旁白按真实语速排布，并附备选的开场钩子 [[1]](#sources)。
3. 拆解智能体起草分镜表（每个镜头一个主体、一个动作、一次运镜）。三个评审智能体并行挑错（摄影指导、剪辑师、观众），导演智能体修改并记录改动；同时运行确定性的检查。在报告的项目中，花钱之前这个小组做了 19 次修改。🛑 **计划**：人批准分镜表 [[1]](#sources)。
4. 团队锁定影像风格：把风格配方（带色温的光线、镜头、色板、调色意图）贴进每个图像和视频提示词；真实的产品照片作为身份参考一并带上。品牌项目在生成前先搭建产品参考流程，以防标签漂移；视觉风格在第三天获得批准 [[1]](#sources)[[2]](#sources)。
5. 智能体并行为每个镜头生成一张分镜关键帧（每帧约五美分），然后生成真实的配音录音，测量时长，并用关键帧搭出按配音定时的动态分镜。🛑 **审阅**：批准动态分镜即锁定剪辑和生成计划（生成秒数 vs 剪辑秒数） [[1]](#sources)。
6. 🛑 **操作**：在人批准分批的视频任务及其总成本估算之前，什么都不会生成；每个项目都有硬性的预算上限 [[1]](#sources)。
7. 视觉模型评判员按六个维度打分；不合格的会得到一句话的纠正方案，作为重新生成排队，且仍需批准。反复出现的失败会变成经验，注入后续的提示词。在品牌项目中，导演审看每一条：审看了 63 条，采用 18 条，约 71% 被拒 [[1]](#sources)[[2]](#sources)。
8. 智能体合成配音、压低在人声之下的生成配乐、渲染好的字幕和片尾卡；无需新的视频生成，即可渲染开头钩子变体和剪短版（6 秒 / 15 秒 / 竖屏） [[1]](#sources)[[2]](#sources)。
9. 🛑 **签发**：品牌对主片进行审阅；在企业内部的案例中，它在第一轮结构化修订后即通过，当天完成 [[2]](#sources)。

**产出：** 一支完成的 30–60 秒广告片，加上开头钩子变体和剪短版，交给品牌/付费媒体团队投放。
**失败模式 → 防护：** 各条之间标签/包装漂移 → 产品参考素材 + 逐帧准确性检查；手与产品的交互失败 → 预留额外的拍摄条数和合成处理；生成的屏幕文字乱码 → 评判员标出，文字改在后期渲染；钱花在最终被剪掉的素材上 → 动态分镜锁定，并在任何视频调用前明确批准支出。
**与相近工作流的区别：** 最接近的是 AWF-0015 AI 镜头工厂。0015 产出剧集，设有计划关卡、逐镜头的评审循环，以及最后的审阅/AI 标识/签发。本工作流交付的是客户的广告片加变体，增加了按配音定时的动态分镜关卡，在任何视频生成之前锁定剪辑，并对每一次生成和重新生成按批次单独审批费用；品牌审阅取代了平台的 AI 标识步骤。从业者若不改动交付物和检查点，无法互相替换。
