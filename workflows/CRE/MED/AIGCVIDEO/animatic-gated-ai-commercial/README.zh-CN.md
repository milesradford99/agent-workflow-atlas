# 动态分镜把关的 AI 广告片

**与相近工作流的区别：** 最接近的是 AWF-0015 AI 镜头工厂。0015 产出剧集，设有计划关卡、逐镜头的评审循环，以及最后的审阅/AI 标识/签发。本工作流交付的是客户的广告片加变体，增加了按配音定时的动态分镜关卡，在任何视频生成之前锁定剪辑，并对每一次生成和重新生成按批次单独审批费用；品牌审阅取代了平台的 AI 标识步骤。从业者若不改动交付物和检查点，无法互相替换。
**工具变体：** `claude-seedance-elevenlabs-remotion` · `nano-banana-kling-veo-premiere`

## 步骤

1. 接收：智能体把产品描述整理成一张卡片式简报（产品事实、受众、一个价值主张、调性、CTA、合规护栏）。🛑 **计划**：人先批准简报，之后才运行其他步骤 [[1]](#sources)。企业内部的品牌实践把简报压缩到一页、一句主线，并在第二天完成概念批准 [[2]](#sources)。
2. 创意总监智能体提出三个不同的概念；人选定一个，智能体写出带时间的节拍脚本（钩子、问题、演示、证明、CTA），旁白按真实语速排布，并附备选的开场钩子 [[1]](#sources)。
3. 拆解智能体起草分镜表（每个镜头一个主体、一个动作、一次运镜）。三个评审智能体并行挑错（摄影指导、剪辑师、观众），导演智能体修改并记录改动；同时运行确定性的检查。在报告的项目中，花钱之前这个小组做了 19 次修改。🛑 **计划**：人批准分镜表 [[1]](#sources)。
4. 锁定影像风格：把风格配方（带色温的光线、镜头、色板、调色意图）贴进每个图像和视频提示词；真实的产品照片作为身份参考一并带上。品牌项目在生成前先搭建产品参考流程，以防标签漂移；视觉风格在第三天获得批准 [[1]](#sources)[[2]](#sources)。
5. 并行为每个镜头生成一张分镜关键帧（每帧约五美分），然后生成真实的配音录音，测量时长，并用关键帧搭出按配音定时的动态分镜。🛑 **审阅**：批准动态分镜即锁定剪辑和生成计划（生成秒数 vs 剪辑秒数） [[1]](#sources)。
6. 🛑 **操作**：在人批准分批的视频任务及其总成本估算之前，什么都不会生成；每个项目都有硬性的预算上限 [[1]](#sources)。
7. 每个片段由视觉模型评判员按六个维度打分；不合格的会得到一句话的纠正方案，作为重新生成排队，且仍需批准。反复出现的失败会变成经验，注入后续的提示词。在品牌项目中，导演审看每一条：审看了 63 条，采用 18 条，约 71% 被拒 [[1]](#sources)[[2]](#sources)。
8. 合成：配音、压低在人声之下的生成配乐、渲染好的字幕和片尾卡；无需新的视频生成，即可渲染开头钩子变体和剪短版（6 秒 / 15 秒 / 竖屏） [[1]](#sources)[[2]](#sources)。
9. 🛑 **签发**：品牌对主片进行审阅；在企业内部的案例中，它在第一轮结构化修订后即通过，当天完成 [[2]](#sources)。

**产出：** 一支完成的 30–60 秒广告片，加上开头钩子变体和剪短版，交给品牌/付费媒体团队投放。
**失败模式 → 防护：** 各条之间标签/包装漂移 → 产品参考素材 + 逐帧准确性检查；手与产品的交互失败 → 预留额外的拍摄条数和合成处理；生成的屏幕文字乱码 → 评判员标出，文字改在后期渲染；钱花在最终被剪掉的素材上 → 动态分镜锁定，并在任何视频调用前明确批准支出。
