# AI 镜头工厂

## 背景

AI 生成剧集是一种短视频故事，画面、动作和声音都来自生成模型，而不是摄影机、演员和动画师。小型工作室和个人创作者为短视频平台制作这类剧集，常见的是漫剧，起点是一份写好的剧本。这项工作是一条链：把剧本拆成镜头，定下每个角色的样子，生成静帧，把静帧变成动态片段，配上声音，最后剪辑。每次生成都像下注，所以大部分精力花在生成大量候选再扔掉其中大多数，以及让同一个角色的脸在每个镜头里保持一致。智能体可以起草分镜表、批量提交生成任务，并对照计划筛选候选。方案和成片仍由导演批准，因为只有人能判断这一集作为故事是否成立；AI 标识和合规检查也必须由人签发，因为发布方要就播出的内容向监管部门负责。

**术语：**
- **漫剧**：动画或漫画风格的短剧；这里指画面和视频由 AI 生成的漫剧。
- **微短剧**：监管部门对单集时长少于 20 分钟、主要在手机上观看的连续短剧的称呼。
- **分镜表（shot list）**：一集内容逐个镜头的计划：每个镜头的编号、景别、运镜、动作、台词和时长。
- **风格帧**：在正式制作前定下整集画面风格的样图。
- **锁定角色**：为每个角色做一套固定的参考图（正面、侧面、背面视图和表情表），在之后每次生成时都喂给模型，让角色始终认得出来。
- **LoRA**：用某个角色的图片训练出的小型附加模型，引导图像模型画出这个角色。
- **关键帧**：一个镜头起始的静止画面，之后再变成动态。
- **图生视频**：由一张静图和一段文字提示生成动态片段。
- **重抽**：因为结果不能用而重新生成一个镜头；也叫抽卡。
- **形变或物理穿帮**：人脸或物体相互融化变形，或者出现现实中不可能的运动。
- **口型同步**：让角色的嘴型与生成的配音对上。
- **钩子**：开头的几秒钟，必须让观众停下来而不是划走。
- **AI 标识（显式/隐式标识）**：观众能看到的显式提示，以及嵌在文件里的隐式标记；国内规定 AI 生成内容两者都要有。

## 用智能体搭建

**形态：** `platform`。关键帧、动作、配音和口型同步来自图像、视频和语音生成模型，通用智能体替代不了。通用智能体可以以 `project` 的形态承担规划、筛选和文书类的步骤：一个 skill 做分镜表，一个子智能体充当关键帧评审，生成平台有 API 的话再用脚本向平台提交批量任务。

**需要：** 以文件形式保存的定稿剧本；工作室所用图像、视频和语音生成平台的账号，如果要用脚本提交批量任务，还需要 API 密钥；以文件形式保存、智能体可读的角色参考图；一个存放候选和选定片段的文件夹；原著以及任何真人肖像的授权。不要让智能体接触视频平台的发布账号。

| 步骤 | 搭建方式 |
|---|---|
| 剧本 → 分镜表 → 🛑 plan | 一个 skill 把剧本整理成分镜表（编号、景别、运镜、动作、台词、时长、提示词），然后停下。 |
| 锁定角色 | 参考图由生成平台制作。skill 记下每个镜头必须用到哪些参考文件。 |
| 每个镜头：(关键帧 ⟲ 评审) | skill 旁边的脚本通过图像平台的 API 提交候选。一个子智能体对照分镜表中的那一行和角色参考图逐张查看候选，返回“保留”或“重抽”并附理由；再由人从保留下来的候选里挑选。 |
| (视频 ⟲ 检查) | 视频平台。同一个子智能体检查每个片段的截帧有无形变或物理穿帮，列出需要重抽的镜头。 |
| 配音 + 口型同步 | 语音和口型同步工具。skill 根据剧本整理出带情绪标签的台词清单。 |
| 剪辑 → 🛑 review | 剪辑工具，不经过智能体。skill 根据分镜表写出剪辑清单，然后停下，等导演给出重抽清单。 |
| AI 标识 → 🛑 sign-off → 发布 | skill 准备一份合规表：哪些镜头是 AI 生成的，显式标识放在哪里，各项素材来自哪里。由人核对后发布。 |

**检查点：** `plan`：skill 把分镜表写入文件后停下，直到导演批准；批量生成要花钱，所以对批量提交脚本设置权限规则，运行前先询问。`review`：skill 交出剪辑清单后停下；导演在剪辑工具里看片，再交回一份重抽清单。`sign-off`：智能体没有上传或发布的工具，也没有平台账号，所以缺少 AI 标识的剧集无法经由它发出；由人签署合规表并发布。

**与来源相比：** 来源和公开实例出自 2025-01 至 2026-07。公开实例描述的是人手工使用生成工具、导演定期审片，都没有提到由智能体来运转这条链；第 3 步里的视觉模型评审也没有引用来源。上面的搭建方式只是针对生成模型之外那些步骤的方案。第 8 步把微短剧监管规定当作征求意见稿引用；来源 14 中的 IT之家 报道说，正式的《微短剧发展管理办法》已于 2026-07-31 发布、2026-09-01 起施行，保留了 AI 生成的剧集每集在明显位置加标识的要求。每个阶段都由人评审的产线是另一个条目：[AWF-0137 Gated AI 漫剧 line](../../SHORTDRAMA/gated-ai-manju-line/)。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 由语言模型把剧本整理成 20–40 个镜头的分镜表。🛑 **计划**：导演批准分镜表和风格帧。
2. 团队锁定角色。从业者会生成正面、侧面、背面视图和表情表，并在之后每次生成时把它们当作参考 [[16]](#sources)。
3. 图像模型为每个镜头并行生成 4 个关键帧候选。由视觉模型评审者过滤，再由人挑选。
4. 视频模型把每个关键帧做成片段（图生视频）。出现形变或物理穿帮时，操作者重抽。
5. 语音模型为每句台词生成带情绪标签的配音，再由口型同步工具对上嘴型。
6. 剪辑师合成整集，并检查前 3 秒的钩子。
7. 🛑 **审阅**：导演列出需要重抽的镜头（回到第 3 或第 4 步）。
8. 🛑 **签发**：由人检查合规与标识。国内规则要求对 AI 生成内容加显式和隐式标识（自 2025 年 9 月 1 日起施行 [[15]](#sources)）。微短剧监管规定的征求意见稿还要求每一集 AI 生成的剧集都在显著位置加标识 [[14]](#sources)。

各步骤报道中用到的工具：

| 步骤 | 工具（国内 / 国外） |
|---|---|
| 分镜表（分镜：编号、景别、运镜、动作、台词、时长） | Doubao, DeepSeek, Claude, GPT |
| 锁定角色 | 即梦 / Midjourney 参考图；ComfyUI + 每个角色一个 LoRA；Kling 多图参考，每次生成 1–4 张参考图 [[17]](#sources) |
| 关键帧 | 即梦/Seedream, Flux, Midjourney |
| 运动 | 可灵 Kling, 海螺 Hailuo, Vidu, Seedance, Veo, Runway |
| 配音与口型同步 | MiniMax, 火山引擎 TTS, ElevenLabs；口型同步工具或原生音视频模型 |
| 合成 | 剪映/CapCut, Premiere |

**报道中的成本（B）：** 一份引用巨量引擎数据的券商报告给出，传统漫剧每分钟 ¥2–5k，AI 辅助制作为 ¥1–2.5k。报告还提到有一家公司把 11 个制作环节缩减为 5 个 [[16]](#sources)。
**示例中应记录的指标：** 每次生成的可用镜头率、每成片分钟的成本、每集耗时。
