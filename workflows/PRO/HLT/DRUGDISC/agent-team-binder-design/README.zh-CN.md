# 智能体团队的结合蛋白设计

**工具变体：** `virtual-lab-gpt4o` · `esm-alphafold-multimer-rosetta`

## 背景

药物和诊断试剂往往从结合体开始：一种能紧紧附着在病毒或细胞上某个选定靶点的蛋白质。纳米抗体是一种类似抗体的小蛋白，是常见的选择。设计它要先选定靶点和思路，再建一条计算流水线，提出成千上万个变体并按预测的契合度排序，挑出一份短名单，然后交给实验室制出这些蛋白，测量它们是否真能结合。研究组需要几位专家才能完成这件事（计算生物学家、机器学习专家、免疫学家），很多实验室并没有。在这里，一个由语言模型智能体组成的团队，每个智能体扮演一位专家，规划项目、编写并运行流水线、提出名单。人类研究员把关方案，并批准名单送去合成，因为制备蛋白要花实验室的时间和经费，而且计算打分不能决定设计有没有用：只有实验室的测量才算数。

**术语：**
- **结合体（binder）**：被设计成附着在选定靶点上的蛋白质。
- **纳米抗体（nanobody）**：一种类似抗体的小蛋白，这里用作结合体。
- **SARS-CoV-2 变异株、刺突 RBD**：COVID-19 病毒的一个版本；RBD 是其刺突蛋白上纳米抗体要结合的部分。
- **PI（首席研究员）智能体**：扮演研究组负责人、主持会议的智能体。
- **Scientific Critic（科学评审）**：对其他智能体的方案和代码提出异议的智能体。
- **ESM、AlphaFold-Multimer、Rosetta**：三种蛋白模型或软件，分别用来给突变序列的可能性打分、预测两个蛋白如何契合、估算所预测契合的结合能量。
- **野生型纳米抗体、突变轮次**：天然存在的起始序列；改动它并重新打分的一轮。
- **从头设计（de novo）**：从零开始设计结合体，而不是改造已知的。
- **湿实验室**：真正制备和测试蛋白质的实验室。
- **表达**：让细胞产出这种蛋白。
- **抗原芯片、多重 ELISA**：同时测量每个纳米抗体与靶点的多个版本结合强度的实验室检测。

## 用智能体搭建

**形态：** `platform`。流水线中的蛋白模型（ESM、AlphaFold-Multimer、Rosetta）和湿实验室检测，通用智能体无法替代。围绕它们的规划与协调可以作为 `project` 运行：用一个 skill 承载会议流程，一个只读的评审子智能体，以及调用蛋白工具的脚本。

**需要：** 作为文件提供的靶点序列和研究员的约束；装有或能访问这三种蛋白工具的计算资源，并有脚本能对一批序列运行每个工具；一个仓库文件夹，供智能体写入方案、流水线代码、打分结果和候选名单；一个同意接收名单的湿实验室。智能体不需要任何下单合成或联系实验室的工具。

| 步骤 | 搭建方式 |
|---|---|
| 人类设定议程 → PI 智能体召开 5 场并行的单独会议 → 合并会议 | 一个 skill。主对话扮演 PI：并行调用五个内置子智能体，各自回答项目需要哪些专家，再在主对话中把答案整合成一个团队。 |
| 就项目方案召开团队会议 → 🛑 plan | 主对话起草项目方案和工具选择，每个专家角色一个子智能体给出意见，另有一个自定义的只读评审子智能体提出异议。skill 写出 `spec.md` 后停下。 |
| 智能体为每个流水线组件编写代码，并经评审循环 | 每个组件一个子智能体写代码；没见过写作过程的评审子智能体来审阅，循环直到评审没有未决异议或达到轮数上限。 |
| (运行突变轮次 + 排序 ⟲ 下一轮) | 脚本运行三种蛋白工具并排序；skill 按方案规定的次数重复这一轮。 |
| 筛出候选序列 → 🛑 sign-off | skill 把名单和打分写入文件后停下。 |
| 🛑 handoff → 结合数据回传团队 | skill 为湿实验室写一份交接说明。结合数据以文件形式回到团队手中供阅读。 |

**检查点：** `plan`：skill 写出 `spec.md` 后停下，并由一个 `PreToolUse` 钩子拦住对流水线文件夹的写入，直到研究员把方案标记为已批准。`sign-off`：智能体没有下单合成的工具，所以由研究员把批准的名单带去实验室。`handoff`：交接说明写明序列、靶点以及请湿实验室做的检测；这些检测由智能体的工具之外的人去做。

**与来源相比：** 来源出自 2025-07（Nature 论文和 Biohub 新闻稿均为 2025-07-29，补充材料为 2025 年）；GitHub 仓库未注明日期，在本次会话中无法打开。最新的来源距本次核对已超过 12 个月，所以查找了更新的记述。同一工作的另一篇述评 2026-01 发表于 International Journal of Biological Sciences（[PubMed](https://pubmed.ncbi.nlm.nih.gov/41522341/)），未打开阅读。Adaptyv Bio 2026-05 的一份案例研究报告，六个完全自主的 LLM 智能体和十支人类团队在一天内针对同一靶点设计结合体，前 100 个设计送去实验室检测（[Adaptyv Bio, 2026-05-13](https://www.adaptyvbio.com/blog/agents-vs-humans)）；它描述的是单个智能体运行一套工具流水线，而不是一队分饰角色的智能体。来源团队自己编写了会议框架。今天的搭建可以用内置子智能体、只读评审和一个 skill 得到同样的结构，不过论文报告的是该框架下的会议，而不是这套搭建方式。分饰角色的智能体团队是否比拥有同样工具的单个智能体做得更好，这些来源并没有说明。来源报告了人类所写字数的占比（0.5% 到约 1%）；本搭建方式不作这类声明。

## 步骤

*以下按来源所述。*

1. 人类研究员说明研究目标和约束（针对近期 SARS-CoV-2 变异株设计纳米抗体结合体），并创建一个 LLM 首席研究员（PI）智能体 [[1]](#sources)。
2. 通过五场并行的单独会议，询问 PI 智能体项目需要哪些专业智能体；再由一场合并会议把五份答案整合成一个团队。在已发表的实例中，产生了计算生物学家、机器学习专家和免疫学家，外加一个常驻的 Scientific Critic 智能体 [[1]](#sources)[[3]](#sources)。
3. 智能体们召开一场团队会议确定项目方案（纳米抗体还是抗体；从头设计还是改造已知结合体），再开一场确定工具栈。🛑 **计划**：人类研究员只在这些会议上给出高层反馈。在项目方案会议中，人类写的内容占 0.5% 的字数，在带评审的单独会议中约占 1% [[3]](#sources)。
4. 在单独会议中，由一位科学家智能体加上 Scientific Critic 产出各个流水线组件；评审提出的异议会驱动多轮修改，之后代码才被接受 [[1]](#sources)[[3]](#sources)。
5. 智能体运行自己设计的流水线（ESM-1b 对数似然比打分、AlphaFold-Multimer 复合物预测、Rosetta 能量打分），从四个野生型纳米抗体（Ty1、Nb21、H11-D4、VHH-72）出发，进行四轮迭代突变，每轮引入一个突变 [[1]](#sources)[[4]](#sources)。
6. 🛑 **签发**：人类负责人接受排名靠前的突变序列清单（92 个新纳米抗体）送去合成，并加上供实验使用的序列标签 [[1]](#sources)[[4]](#sources)。
7. 🛑 **接手**：独立的湿实验室团队针对原始株和近期的刺突 RBD，进行纳米抗体表达、RBD 表达、抗原芯片打印和多重 ELISA；结果连同计算打分和完整的智能体对话记录一并发表 [[1]](#sources)[[2]](#sources)。

**产出：** 一组排好序的设计结合体序列，以及产生它们的计算流水线，交给湿实验室；ELISA 结合数据和完整的会议记录公开发布。
**失败模式 → 防护：** 智能体停留在含糊的角色定义或过于激进的从头设计 → 并行会议加合并会议，并在每场会议中设置 Scientific Critic 智能体。智能体写出看似合理但有误的代码或打分公式 → 组件级的评审循环，以及人工审阅最终流水线。计算打分无法预测结合 → 以湿实验室 ELISA 作为唯一被接受的结论（92 个设计中，有两个对 JN.1 或 KP.3 的结合有所改善）。
**与相近工作流的区别：** 最接近的是同类的 AWF-0034 化学家把关的 DMTA 循环。替换测试不通过：AWF-0034 的交付物是高通量实验的反应网格和操作步骤，由化学家在运行前修正，并在每个循环中挑选候选清单；本工作流的交付物是由智能体自己设计的流水线产出的蛋白序列，人工检查点是会议层面的议程反馈（约占 1% 的字数）加合成前的一次签发，验证则是交给独立的湿实验室团队做 ELISA，而不是由提出方案的化学家在实验台上小规模重复。自主程度也更宽松：检查点之间，智能体自己编写并运行工具。

## 公开实例

覆盖度（截至 2026-11-13）：**充分**：有详细的第一手实例，与流程的大部分环节一致。收集与复核见 [Fourth collection pass](../../../../../research/2026-11-fourth-pass.md)。

- [Swanson, Wu, Bulaong, Pak & Zou, The Virtual Lab of AI agents designs new SARS-CoV-2 nanobodies](https://www.nature.com/articles/s41586-025-09442-9) (2025-07-29)。智能体团队设计了自己的流水线；设计经湿实验室 ELISA 确认。"designed 92 new nanobodies"; "two new nanobodies exhibit improved binding to the recent JN.1 or KP.3 variants". *第一手：是；可信度：高。*
- [Swanson et al., Supplementary Information, Supplementary Note 3](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-025-09442-9/MediaObjects/41586_2025_9442_MOESM1_ESM.pdf) (2025)。量化了人类在每个检查点的贡献有多少。"with the human researcher only writing 0.5% of the words" (project specification team meeting). *第一手：是；可信度：高。*
