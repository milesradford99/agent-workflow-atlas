# 化学家把关的 DMTA 循环

**工具变体：** `gpt-5-4-maria-lab` · `generative-model-robotic-synthesis`

## 背景

研发新药是一个不断重复的循环，化学家称之为设计、制备、测试、分析（DMTA）：决定要试哪些化合物或反应，把它们做出来，测量结果，再用学到的东西决定下一轮。每一轮都要花团队的时间和实验材料，所以选对下一步要试什么非常值钱。在这里，语言模型阅读目标，提出并排序想法，实验室智能体把选中的想法转成实验方案，由自动化实验室成批运行；模型再读取结果，提出下一轮。化学家决定哪些想法可以进入实验室，在任何实验运行之前修正流程，并在成果写成报告之前亲手重复有代表性的结果。他们不能被去掉：哪些实验可以运行由他们把关，而且微量的自动化实验得出的结果，放到化学家实际工作的规模上未必成立。

**术语：**
- **DMTA 循环**：设计、制备、测试、分析；药物研发中不断重复的循环。
- **HTE（高通量实验）**：在自动化实验室里并行运行大量微量反应，按条件排成网格。
- **偶联反应、底物**：把两个分子连接起来的反应；底物是投入反应的起始原料。
- **产率（yield）**：反应实际得到的产物占理论上可得产物的比例。
- **台架规模（bench scale）**：化学家手工操作的常规规模，比 HTE 的一个孔大得多。
- **引导与评分提示词**：科学家用来告诉模型目标是什么、如何给它的想法打分的指令。
- **预印本**：在正式期刊评审之前公开分享的研究报告。

## 用智能体搭建

**形态：** `platform`。实验在自动化的高通量实验室里运行，并由化学家在台架上确认，通用智能体无法替代。通用智能体可以作为 `skill` 承担文字环节（给方案排序、编写实验网格、分析结果），每个停点都有化学家在对话中。

**需要：** 作为文件提供的目标和化学家的引导与评分提示词；智能体可以读取的文献和以往结果；自动化实验室的网格格式及其返回的数据，同样是文件；一位负责选定方案、修正流程并亲手重复结果的化学家。不要让智能体接触实验室的任务提交界面和仪器控制。

| 步骤 | 搭建方式 |
|---|---|
| 开放目标 + 引导提示词 → 生成并排序方案 | skill 读取目标、提示词和各个文件，写出排好序的方案清单，并说明每项排名的理由。 |
| 🛑 plan (化学家选定候选清单) | 见“检查点”。 |
| 智能体编写 HTE 实验网格 | skill 把每个选定的想法写成实验室格式的网格文件：试剂、用量、条件、板上布局。 |
| 🛑 review (化学家修正实验流程) | 见“检查点”。 |
| (运行 HTE + 分析 ⟲ 提出下一轮) | 实验室运行这些网格。skill 读取返回的数据、做分析并写出下一轮方案；化学家先审阅，再运行下一个循环。 |
| 🛑 sign-off (化学家在台架规模复现) → 预印本 | 见“检查点”。 |

**检查点：** `plan`：skill 最后列出排好序的方案后停下；由化学家选定要测试哪些，没有化学家标记的方案，智能体不会为它写网格。`review`：skill 写完网格后停下；化学家自己修改并载入实验室，因为智能体无法访问实验室的提交界面。`sign-off`：化学家手工重复有代表性的反应，并判断结果是否成立；智能体可以根据数据和化学家的台架结果起草报告，但没有任何能把它发布出去的工具。

**与来源相比：** 来源出自 2026-06（两篇文章，均为 2026-06-22）和 2026 年（Google 预印本，未注明月份）。它们都很新，所以没有另行查找更新的记述。两篇主要报道是对一家公司公告的新闻报道，依据的是公司自己的说法；它们所述的预印本不在已打开的来源之列。所描述的系统把一个前沿模型、厂商的化学智能体和一个自动化实验室结合在一起；上面的搭建方式只覆盖文字环节，其余依靠实验室。适配体论文（来源 3）描述了与湿实验室的闭环，但摘要没有说明人在哪里批准，所以它支撑不了这套搭建中的检查点。在一类反应上的结果并不能说明该方法可以推广到其他反应或底物；来源自己也这样说。

## 步骤

*以下按来源所述。*

1. 科学家写下目标以及引导/评分提示词。模型生成研究方案并排序 [[1]](#sources)[[2]](#sources)。
2. 🛑 **计划**：化学家审阅排名靠前的方案，并批准要测试哪些 [[1]](#sources)[[2]](#sources)。
3. 实验室智能体把选定的想法转成高通量实验（HTE）流程 [[1]](#sources)。
4. 🛑 **审阅**：在运行之前，化学家对实验流程做修正（被描述为小幅修改）[[1]](#sources)[[2]](#sources)。
5. 实验室运行并分析实验。模型重新分析数据并提出下一轮 [[1]](#sources)。
6. 🛑 **签发**：化学家在台架规模手工重复有代表性的反应，在撰写报告前验证结果 [[1]](#sources)[[2]](#sources)。

**产出：** 一个经验证的反应或分子结果，附 HTE 数据和台架规模的确认，整理成预印本供外部专家评审。
**失败模式 → 防护：** 微量规模的假象 → 台架规模的人工重复 [[1]](#sources)。夸大自主性或通用性 → 实验方自己说明结果可能无法推广到其他反应或底物 [[2]](#sources)。安全范围 → 由人控制哪些方案进入实验室 [[2]](#sources)。
**与相近工作流的区别：** 暂无相近的。AWF-0023 事件驱动的模型更新（Event-driven model update，INVEST）属于不同领域。
