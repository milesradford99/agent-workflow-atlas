# 放射片报告预生成

**工具变体：** `in-house-vit-opt-powerscribe`

## 背景

拍完一张 X 光片后，由放射科医生看片并写报告，开检查的医生再根据这份报告采取行动。放射科医生每天要读大量检查，通常是对着报告系统口述，每份报告里有很多例行措辞，每项检查都要重新写一遍。在这里，医院用自己过去的 X 光片和报告训练了一个模型，影像一拍完它就起草报告，并放进放射科医生的听写模板里。放射科医生仍要看片，像对待实习医生的草稿那样核对、修改，然后定稿，因为报告是以他们的名义发出的医疗记录，漏掉或编造一个发现都可能伤害患者。

**术语：**
- **放射片、检查**：普通 X 光影像；一项检查是针对一次申请一起拍摄的一组影像。
- **对照检查**：同一患者早先的放射片，与新片放在一起看有什么变化。
- **临床提示**：这里指随影像一起交给模型的信息：放射科医生姓名、检查项目、检查原因和对照间隔。
- **听写系统、模板**：放射科医生口述或输入报告所用的软件（这里是 PowerScribe），以及其中预设的报告格式。
- **实习医生草稿**：在教学医院里，由住院医生起草报告，再由上级放射科医生修改。
- **EHR（电子病历）**：医院保存每位患者病历的系统；这里是 Epic。
- **推理时间**：模型生成一份草稿所用的时间。
- **补充说明（addendum）**：报告定稿后再做的更正或补充；补充说明率被用作质量信号。
- **同行评议**：由其他放射科医生对一部分报告的准确性和质量打分。
- **词错误率**：这里指草稿中被放射科医生改动的词所占比例。
- **气胸；影子运行**：肺塌陷，属于紧急发现；在真实数据上运行某个工具，但不把输出展示给临床医生。

## 用智能体搭建

**形态：** `platform`。草稿来自一个用医院自己的放射片和报告训练的图像到文本模型，并出现在 EHR 的听写流程里；这两样通用智能体都替代不了。通用智能体可以以 `service` 的形态承担监测这一步。

**需要：** 由医院搭建和运行的报告生成模型，以及它与 EHR 和听写系统的连接；监测服务需要一份已定稿报告、补充说明和同行评议分数的只读导出，尽量去掉患者身份信息，并保存在医院批准处理患者数据的环境中。不要给监测用的智能体任何修改报告的工具。

| 步骤 | 搭建方式 |
|---|---|
| 放射片采集完成 → EHR 发送当前与对照影像及临床提示 (放射科医生、检查项目、检查原因、对照) | EHR，以及医院与模型服务器之间的集成。 |
| 生成报告草稿 | 图像到文本模型。 |
| 草稿出现在听写系统的模板字段中 | 听写系统。 |
| 🛑 review (放射科医生像审阅实习医生草稿一样核对并修改) → 最终报告 | 由放射科医生在听写系统中完成。 |
| 跟踪补充说明 + 同行评议抽样 | 用云端定时任务或 `claude -p` 按计划对导出数据运行：由脚本按影像专科比较有草稿和无草稿检查的补充说明率，并抽取同行评议样本；智能体为放射科质量负责人写出汇总。 |

**检查点：** `review`：草稿只是放射科医生所选模板中的一个字段；报告由放射科医生在听写系统中定稿，本搭建中没有任何智能体能接触到它。监测服务读取的是导出数据，不能修改报告。

**与来源相比：** 来源和公开实例都出自 2025-06。截至 2026-11 未找到更新的记录。来源描述的是一家医疗系统自建、并接入其 EHR 和听写系统的定制视觉模型；没有智能体在运行这些步骤，所以通用智能体能做的只限于监测这一步。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 采集完成后，EHR（Epic）把影像和临床数据发送到院内服务器。模型看到的是拼在一起的当前影像与对照影像，以及放射科医生姓名、检查项目、检查原因和对照间隔 [[1]](#sources)。
2. 模型写出报告草稿。推理时间中位数为 3 秒 [[1]](#sources)。
3. 听写系统把草稿显示在 PowerScribe 模板的自定义字段中，由放射科医生选用该模板 [[1]](#sources)。
4. 🛑 **审阅**：放射科医生在常规流程中核对并修改草稿，方式与修改实习医生的草稿相同 [[1]](#sources)。
5. 医院按院区和影像专科分阶段推广。它监测补充说明率，并对一部分报告做同行评议，检查准确性和质量 [[1]](#sources)。
6. 可选：用影子运行筛查生成的文本中是否有意外的气胸。研究期间，其告警没有展示给临床医生 [[1]](#sources)。

**产出：** 由放射科医生定稿、存入 EHR 的放射片报告。
**失败模式 → 防护：** 非胸部检查需要更多修改（词错误率中位数 0.63，胸部为 0.31）→ 按专科分阶段推广。质量可能在无人察觉时漂移 → 对比补充说明率（0.14% 对 0.13%），并对 800 项检查做同行评议。
**与相近工作流的区别：** AWF-0026 环境记录员（Ambient scribe）是最接近的一个，它根据经同意的音频起草就诊记录。本工作流则是根据影像起草，没有同意或录音环节，并把草稿放进阅片医生的听写模板里，每项检查只审阅一次。

## 公开实例

覆盖度（截至 2026-11-06）：**充分**：有详细的第一手实例，与流程的大部分环节一致。收集与复核见 [Second collection pass](../../../../../research/2026-11-second-pass.md)。

- [Huang et al., Northwestern Medicine, JAMA Netw Open](https://jamanetwork.com/journals/jamanetworkopen/fullarticle/10.1001/jamanetworkopen.2025.13921) (2025-06-05)。在一个拥有 12 家医院的系统中进行的前瞻性队列研究，11,980 份模型辅助的放射片报告与匹配的对照比较。"a 15.5% increase in per-study documentation efficiency"。*第一手：是；可信度：高。*
