# 合规义务清单构建

**与相近工作流的区别：** AWF-0025 有据可查的法律备忘录（Grounded legal memo，RESEARCH）回答单个法律问题。本工作流则构建并维护一份与控制措施对应的长期清单，并按周对比变更。
**工具变体：** `llm-xml-ingest-pipeline`

## 步骤

1. 确定法规来源的范围并分级。定制的流水线把 HTML、PDF 和扫描文本抓取成客户模板下的结构化 XML [[1]](#sources)。
2. LLM 识别、概括并标注每项义务，把文本拆解为对应各主题的独立条款，并通过语义检索关联相关规则和指引 [[1]](#sources)。
3. 🛑 **审阅**：律所律师核查 LLM 的所有输出。提示词与领域专家一起迭代 [[1]](#sources)。
4. 针对每项义务，LLM 把机构的控制措施、标准和政策汇总到同一处，并做主题式审查 [[1]](#sources)。
5. 🛑 **签发**：律师判断各项义务对应的控制措施是否充分，由此形成义务清单 [[1]](#sources)。
6. 每周自动更新：LLM 读入新旧法规文本，概括变化及其对业务的影响，用于利益相关方简报 [[1]](#sources)。
7. 🛑 **审阅**：律师在每份简报送达客户之前逐份检查 [[1]](#sources)。

**产出：** 一份经法律审阅、与内部控制措施对应的义务清单，并通过每周的变更摘要保持更新。它为控制措施映射、前瞻性监测和 GRC 工具提供输入。
**失败模式 → 防护：** 难以区分真正的法律变更与编辑性改动，以及各来源和辖区之间的数据重叠 → 结构化摄取，加上律师审阅每一项输出 [[1]](#sources)。
