# 生成式题库

**与相近工作流的区别：** 最接近的是 AWF-0028 锚点校准评分器（ASSESS），它给学生作答打分。本工作流生成的是试题本身，经专家组的内容与公平性审题以及试测心理测量把关，因此产出和检查点不同。
**工具变体：** `gpt3-duolingo-item-factory` · `gpt4`

## 步骤

1. 语言模型以每种体裁 3–5 个示例为样本，生成数千篇三种体裁（新闻、说明文、叙事文）的阅读材料 [[1]](#sources)。
2. 自动过滤器按长度、重复的 8-gram、冒犯性内容和句子似然度阈值剔除材料 [[1]](#sources)。
3. 每篇材料生成完整题组：语境词汇、文本补全、两道理解题、主旨与标题，并附生成的干扰项 [[1]](#sources)。
4. 🛑 **审阅**：每道题由 12 名外部审题员和 6 名内部审题员给出至少 3 份内容审题意见和 2 份公平性审题意见，再经裁决；789 篇材料中有 454 篇留存 [[1]](#sources)。后来的 DET 流水线在专家编辑润色、事实核查和偏见审查之前，增加了自动化的语言和社会适宜性检查 [[2]](#sources)。
5. 留存的材料在免费练习测试结尾试测，然后做心理测量分析。未通过区分度分析的干扰项会被剔除 [[1]](#sources)。
6. 🛑 **签发**：测评团队将已校准的题目接收进正式题池 [[1]](#sources)[[2]](#sources)。

**产出：** 一个经过审阅、试测校准的题池，用于高风险的自适应测试。
**失败模式 → 防护：** 行文流畅但有缺陷或带偏见的题目 → 多名审题员做内容与公平性审题并裁决，再用试测统计验证 [[1]](#sources)。干扰项薄弱 → 区分度分析将其剔除；相关系数低于 0.1 的题目从约 6% 降到 2% [[1]](#sources)。

## 公开实例

覆盖度（截至 2026-11-06）：**充分**：有详细的第一手实例，与流程的大部分环节一致。收集与复核见 [Second collection pass](../../../../../research/2026-11-second-pass.md)。

- [Attali et al., The interactive reading task](https://www.frontiersin.org/articles/10.3389/frai.2022.903077/full) (2022-07-22)。Duolingo English Test 生成的阅读材料、多名审题员筛选、约 20 万场次试测。"a final set of 454 out of 789 passages (58%) were retained"。*第一手：是；可信度：高。*
