# 逆向设计课程开发

## 步骤

1. 从课程标准和课程目标出发：教师设定年级、学科和目标布鲁姆层级 [[1]](#sources)，并概述课程目标 [[2]](#sources)。然后用 AI 起草可衡量的课程级和模块级学习目标，再逐步打磨 [[2]](#sources)。在 ARCHED 中，一个智能体生成学习目标，另一个按教学标准分析这些目标，并绘出各认知层级的分布；教师可重新生成并选择保留哪些 [[1]](#sources)。
2. 🛑 **计划**：教师批准学习目标集合，重点检查“理解”附近相邻层级的布鲁姆分类，因为分类错误多集中在这里 [[1]](#sources)。
3. 编写与每个学习目标对齐的评估和评分量规。TWU 的示例提示词要求为分步作业的每一部分给出评分量规，再由教师调整 [[2]](#sources)。ARCHED 没有对评估题的生成效果做评测 [[1]](#sources)。
4. 把模块计划做成课程地图，将材料、活动和评估与学习目标关联起来 [[2]](#sources)。
5. 🛑 **计划**：在制作任何课时材料之前，教师先批准课程地图。
6. 对每个课时，结合年级、时间限制和学生的薄弱环节等背景生成材料（讲稿或幻灯片内容、讨论题、活动、分步作业）[[2]](#sources)，并生成分层版本。
7. 把每个生成的条目加入课程地图，以检查每个学习目标都有对应评估 [[2]](#sources)，再检查准确性和无障碍。
8. 🛑 **审阅**：教师凭自己的学科知识审阅全部内容，教学设计师从旁协助 [[2]](#sources)。
9. 把批准后的课程导入 LMS。ARCHED 没有 LMS 集成，一位试点专家认为这是一个缺口 [[1]](#sources)。

**产出：** 一门对齐的课程（学习目标、带评分量规的评估、模块地图和课时材料），已导入 LMS。
**失败模式 → 防护：** 学习目标归入了错误的布鲁姆层级 → 分析环节加教师审批 [[1]](#sources)。AI 规划整门课程或取代教师的专业判断 → 采用人在回路的方式，由教师迭代并决定 [[2]](#sources)。材料偏离学习目标 → 课程地图的对齐检查 [[2]](#sources)。学生隐私 → 绝不向 AI 提供学生或学校的个人信息 [[2]](#sources)。
