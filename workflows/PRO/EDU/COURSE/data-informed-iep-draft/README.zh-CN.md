# 数据支持的 IEP 草案

**工具变体：** `panorama-education`

## 背景

在美国公立学校，符合条件的残障学生可以享有特殊教育，并拥有一份个别化教育计划（IEP）：法律要求的书面计划，写明该生的目标和学校将提供的服务。IEP 由特教教师撰写，依据学生的记录，这些记录分散在学区的多个系统里；随后由包括家长和学校人员在内的团队开会商定。每名学生的记录汇总和初稿撰写要花几个小时。智能体负责收集数据、指出规律并填写学区的模板，凡是记录不能支持的内容一律留空。每一项目标和服务仍由人来决定，因为这份计划对学区具有法律约束力，并决定学生能得到什么，而团队的认可是一个不能委托他人的法定环节。

**术语：**
- **IEP（个别化教育计划）**：针对一名学生的特殊教育目标和服务的、具有法律约束力的书面计划。
- **特教教师**：受过训练、负责撰写和执行 IEP 的教师。
- **IEP 团队**：包括学生家长和学校人员的小组，在会议上商定计划。
- **干预措施**：写入计划的具体支持或教学方法。
- **学区平台**：学区自己的系统，保存出勤、成绩和其他学生记录。

## 用智能体搭建

**形态：** `skill`。特教教师一次起草一名学生的 IEP，并且全程在对话中，所以一个读取记录、填写模板并停下的 skill 就够了。

**需要：** 通过 MCP 连接器或导出文件，对这一名学生出勤和各科记录的只读访问；学区的 IEP 模板，作为 skill 填写的文件；一套经学区审查过合规和学生隐私的环境，就像来源中的学区对它的工具所做的那样，而不是通用聊天机器人。每次只让智能体接触一名学生，并且不给它任何能写入学区系统或发送文件的工具。

| 步骤 | 搭建方式 |
|---|---|
| 从学区系统提取学生数据 | 一个 MCP 连接器或导出脚本，只读地返回这一名学生的记录。 |
| 找出优势与不足 | skill 把记录中的规律汇总出来，作为撰写目标的参考。要求它不要把目标或干预措施当作决定提出来。 |
| 填写 IEP 模板，标记空白字段 (不编造内容) | skill 填写模板，对数据不能支持的字段写上 `NOT IN RECORDS`。由脚本检查没有哪个字段是空的却没有这个标记。 |
| 🛑 review | skill 呈现草案和空白字段清单后停下。由特教教师写出目标和服务。 |
| 🛑 sign-off | IEP 团队开会并在学区自己的流程中签字；智能体没有发送、归档或签字的工具。 |

**检查点：** `review`：skill 最后给出草案和空白字段清单，然后停下；目标和服务由特教教师填写。`sign-off`：签发就是现有的法定 IEP 流程；智能体没有邮件、归档或签字工具，它的连接器也是只读的。

**与来源相比：** 唯一的来源出自 2026-10。它是一篇关于某学区自己工具的新闻报道，没有介绍内部如何运作，所以这些步骤是向记者介绍的样子，这套搭建方式是本目录的设计，不是那个工具。`variants` 中的工具（`panorama-education`）是一个厂商平台。带 skill 的通用智能体没有与学区系统的内置连接，连接器及其隐私审查要由学区自己安排。来源说学区在上线前对该平台做了州和联邦合规以及学生数据隐私方面的审查；这套搭建方式无法证明这类审查已经完成。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 工具从学区的多个平台提取每名学生的记录，例如出勤趋势和学生吃力的科目 [[1]](#sources)。
2. AI 寻找规律、优势和不足，为撰写目标提供参考。它并不用于作出 IEP 决定，也不用于指定干预措施 [[1]](#sources)。
3. 工具依据学区的 IEP 模板起草文件，对不知道的字段标记为空白，而不是编造内容 [[1]](#sources)。
4. 🛑 **审阅**：特教教师对目标和干预措施作最终决定 [[1]](#sources)。
5. 🛑 **签发**：草案交给 IEP 团队。文章没有描述这一阶段；它就是现有的法定 IEP 流程，学区表示该工具不会改变这一流程 [[1]](#sources)。
6. 上线之前，该平台经过学区的审查，确认符合州和联邦的合规要求以及学生数据隐私要求 [[1]](#sources)。

**产出：** 经教师审阅、带到 IEP 团队会议上的 IEP 草案。
**失败模式 → 防护：** 数据分散在多个系统、AI 偏见以及推理过程不透明，这些都是一位隐私倡导者提出的 → 使用经学区审核的平台，而不是通用聊天机器人，并做合规与隐私审查；这位倡导者还呼吁告知家长并提供退出选项，学区尚未这样做 [[1]](#sources)。编造内容 → 工具标记空白，而不是填充内容 [[1]](#sources)。
**与相近工作流的区别：** 最接近的是 AWF-0027 逆向设计课程（Backward-design course，COURSE），它为整个班级设计课程。本工作流则是依据单个学生的记录起草具有法律约束力的个别化计划，由特教教师和 IEP 团队把关，风险较高。分类说明：IEP 也涉及评估，但它的产出是一份教学计划。
