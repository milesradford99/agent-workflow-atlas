# 投稿入口筛查

**与相近工作流的区别：** 最接近的是 AWF-0046 评审意见的再评审反馈（PEER），它检查审稿人写的评审意见，并私下向审稿人反馈。本工作流在入口处筛查稿件本身，服务于编辑部，且在评审开始之前进行。产出和检查点的负责人不同。
**工具变体：** `frontiers-aira`

## 背景

期刊编辑部在审稿人之前看到每一份投稿，而这也是唯一能便宜地拦下一篇稿子的地方。送审之后再拦，代价是审稿人无偿的时间、编辑的决定信和一次申诉；送审之前拦，代价是一次检查。检查要找的东西变起来比检查本身更快：十年前的问题是重复文字，现在则是按需组装的稿件——图看起来合理、参考文献都是真论文却被引来支持它们没说过的话、作者可能并不存在。这些信号单独看都很弱——一块可疑地均匀的印迹、一条撑不住那句话的引注、与另外六份投稿共用的通讯地址——所以设计上要做许多便宜的检查而不是一个强检查，产出也应当是一份带建议的疑点清单而不是一个决定。编辑读这些标记，决定这篇稿子还要不要送审。真正在持续改进的是那个闭环：编辑推翻一个标记时，这次更正就是训练数据，于是下一个版本是对着专家判断来衡量，而不是对着厂商的基准。

**术语：**
- **入口（intake）**：从投稿到分配给编辑或审稿人之间的环节。
- **图像完整性（image integrity）**：检查图形是否被重复使用、拼接或篡改。
- **论文工厂（papermill）**：批量制造论文并出售署名的机构。
- **抄袭检查（plagiarism check）**：与已发表文本和预印本比对，通常给出相似度分数。
- **利益冲突（conflict of interest）**：作者与编辑或审稿人之间使其不适任的关系。
- **标记精确率（flag precision）**：被标记的条目中确实是真问题的比例。
- **误标（false flag）**：被专家澄清的标记条目，是规模化筛查的主要成本。
- **网络信号（network signal）**：跨投稿而非单篇之内的模式，例如共用作者或基础设施。

## 用智能体搭建

**形态：** `service`。每份投稿一到就筛，无人值守，覆盖一家出版社的全部收稿；编辑看到的是标记而不是自己去跑什么；更正则回灌成重训闭环。这就是最朴素意义上的服务——持续入口、不按件触发人工、一条负责分流的队列。

**需要：** 稿件及其图形文件以检查可读的形式提供，包括原始图像而不是拼好的 PDF；相似度服务、撤稿与论文工厂数据库、引文索引，因为检查的好坏只等于它所查询的数据；带严重度分级的标记分类法，因为"20 项检查"一起喊同样大声就是噪音；一个给编辑的视图，显示每个标记背后的证据而不只是名字；把推翻记录为带标签的样本，这才是重训得以发生的原因；以及稿件数据的留存政策，因为筛查意味着替别人保管未发表的东西。智能体不能拒稿，也不能就某个标记联系作者：拒稿是编辑的决定，而在被证伪之前，指控本身就是诽谤。

| 步骤 | 搭建方式 |
|---|---|
| 每份投稿：AI 检查 | 一条由投稿触发的队列，并行跑完检查集，每项结果连同它检查的物件一起存下，因为编辑要看的是那块印迹，不是一个分数。 |
| 最多 20 条建议 | 一份带严重度与证据链接的排序清单，并设上限，好让编辑的注意力落在最上面几条而不是均摊在二十条上。 |
| 无问题：交给编辑 | 干净路径自动且静默，这才让体量付得起；一篇通过的稿子应当不占编辑任何时间。 |
| 🛑 被标记：review（编辑决定是否送审） | 编辑看到标记、打开证据，决定是送审、问作者还是退稿；搭建自己不能退稿。 |
| 专家更正 → 重新训练模型 | 每一次推翻都连同编辑的理由存为带标签的样本；重训在发布前对着这些判断评测。 |

**检查点：** `review`：每个标记都是给编辑的问题，从不是决定，而搭建没有任何退稿通路——这在法律上和编辑上都重要，因为错误指控学术不端是这里最贵的失败。

**与来源相比：** 来源出自 2020-07 与 2023-06，是本组里证据最旧的条目：一篇 IEEE Spectrum 访谈和一篇出版社博客。两份本轮都没有重新打开；打开的是该出版社现行的科研诚信页面，以及 2026 年关于诚信工具市场的报道。此后有这些变化：检查数量、误标率与分析单位都变了。AIRA 现在几秒内跑 40 多项检查，而本条目形状里记的是 20 项；出版社自己的说法是，诚信团队在稿件到达责任编辑之前就拦下并退掉约 32%——远高于 2020 年那篇访谈所暗示的干预率。行业基础设施也到位了：STM 诚信中心每月在参与的出版社之间筛查逾 125,000 份稿件，标出约 1,000 例疑似论文工厂案件，该出版社此后又在自己系统上叠加了第三方工具。流行度数字解释了这笔投入：2026 年的估计认为，近期肿瘤研究论文中约 10% 牵涉论文工厂，某些癌种超过 20%；一项《柳叶刀》审计发现，PubMed 论文中每 277 篇就有 1 篇引用了编造的参考文献，而其中 98% 未作任何处理。对这套搭建有两点教训，都是形状层面的。第一，分析单位已从稿件移到网络：跨论文的共用作者、地址与投稿模式能抓到单篇检查抓不到的东西，所以流水线应保留这些字段并支持跨投稿查询——这是本条目形状里没有的一项。第二，高干预率使误标成为主要成本，而唯一的防线就是设计里已有的那条：编辑看证据、作决定，并把推翻记录下来。没有变的是：标记不是认定。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 每一份来稿在到达时即由 AIRA 自动检查，AIRA 内建于该出版社的同行评审平台 [[1]](#sources)。
2. 检查覆盖语言质量、图形与图像完整性、抄袭与利益冲突，速度为"每秒最多 20 项检查" [[1]](#sources)[[2]](#sources)。
3. AIRA 给出最多 20 条建议并标出问题；它还会推荐编辑与审稿人 [[1]](#sources)。
4. 🛑 **审阅**：编辑与审稿人依据结果决定一篇稿件是否进入同行评审；AI 标出疑点，由人决定 [[1]](#sources)[[2]](#sources)。
5. 专家反馈（包括被更正的错误）成为训练数据，模型定期重训 [[1]](#sources)。

**产出：** 每份投稿在同行评审开始之前，带着完整性与质量标记到达责任编辑。
**失败模式 → 防护：** 图像上的误标——被标记的图像中只有约 10% 真有问题是 → 每个标记都由人决定 [[1]](#sources)。欺诈手法变化导致模型漂移 → 用专家更正重训 [[1]](#sources)。
