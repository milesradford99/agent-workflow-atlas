# 挑战者代理投委会备忘录

**工具变体：** `schroders-gaiia` · `v7-go`

## 背景

投资机构在拿出资金投向一家公司之前，交易团队要先研究这家公司（称为尽职调查），再为投资委员会写一份备忘录；投资委员会是批准或否决交易的资深小组，并据此决策。备忘录概括公司、市场和风险。从一大堆交易文件写出初稿要花好几天，而照着标的公司自己的宣传材料写，初稿往往只是把宣传再说一遍。在这里，分析智能体起草备忘录，第二个智能体（挑战者）依据本机构过往交易的记录提出质疑。随后交易团队权衡这些质疑，并补充自己对风险的判断。备忘录和决策仍归人负责，因为机构及其投资专业人员要就每一项投资向客户负责。

**术语：**
- **投委会备忘录（IC memo）**：投资委员会备忘录，委员会决策前阅读的文件。
- **尽职调查**：投资之前对公司的财务、业务和法律状况的核查。
- **数据室**：公司向潜在投资人开放的共享文件夹，里面是各类文件。
- **联合投资**：与牵头的另一家机构一起投资同一笔交易。
- **挑战者**：第二位审阅者，职责是反驳草稿，让弱点在委员会开会之前暴露出来。
- **交易团队**：负责某一笔交易的投资专业人员。

## 用智能体搭建

**形态：** `project`。挑战者必须是没有见过草稿如何写成的审阅者，并且依据常设的项目知识（本机构过往交易）工作，所以一个 skill 不够。

**需要：** 作为文件的交易文件和尽职调查问题；机构的备忘录模板；作为参考文件、供挑战者读取的本机构过往交易记录；一套经机构批准、可以处理保密交易文件的环境。不要给任何智能体发送、归档或记录投资决策的工具。

| 步骤 | 搭建方式 |
|---|---|
| 交易文件 + 尽职调查问题 → 分析代理起草投委会备忘录 | 一个 skill 读取文件、回答问题，按机构模板写出备忘录，每条论断都链接到来源文件。 |
| 投委会代理提出质疑 | 一个自定义的只读子智能体，只接收草稿和过往交易参考文件，返回质疑意见：行业动态、商业模式、风险因素。 |
| 🛑 review (交易团队权衡质疑并补充自己的风险判断) | 见“检查点”。 |
| (重新起草 ⟲ 🛑 review) | skill 根据交易团队的批注和质疑意见重新起草，然后再次停下。 |
| 🛑 sign-off (投资委员会决策) | 见“检查点”。 |

**检查点：** `review`：草稿和质疑意见写入文件后，skill 停下，由交易团队修改并补充自己对风险的判断；每次重新起草后都在同一处再次停下。`sign-off`：委员会在智能体之外决策，智能体没有记录或发送决策的工具。

**与来源相比：** 来源出自 2025-06 至 2026-07（第二个页面显示日期为 2026-07-22，而条目把它列为未注明日期）。来源 1 是一家机构对自家内部工具的发布公告，来源 2 是厂商对自己产品的介绍，所以都看不到内部的步骤。这套搭建方式只是对它们的一种解读。来源没有说明挑战者如何调用机构的历史数据；这里用的是参考文件。V7 变体中可追溯的引用是产品功能，在这套搭建方式里只是写在 skill 里的一条规则。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 分析智能体（GAiiA）在直接投资和联合投资的尽职调查中筛查大量交易数据，回答投资相关的具体问题，并起草投委会备忘录的初稿 [[1]](#sources)。
2. 一个独立的虚拟投资委员会智能体审阅草稿，基于本机构的历史投资数据，补充行业动态、商业模式考量和风险因素方面的意见 [[1]](#sources)。
3. 🛑 **审阅**：交易团队成员评估并扩展投委会智能体的反馈，加入自己对风险和机会的判断，并可要求分析智能体给出改进版本 [[1]](#sources)。
4. 每次重新起草后，都再次交给交易团队 🛑 **审阅**，之后文件才定稿 [[1]](#sources)。
5. 🛑 **签发**：每一项投资决策都只由投资专业人员作出 [[1]](#sources)。一个风险投资（VC）变体：团队把整个数据室放进工具，得到按机构模板生成、每条论断都链接到来源的备忘录，并加以核对 [[2]](#sources)。

**产出：** 以机构自有格式定稿的投资委员会备忘录，交付投资决策。
**失败模式 → 防护：** 草稿照搬标的公司自己的宣传 → 设置独立的挑战者智能体，以本机构过往交易为依据。编造的数字进入投委会 → 论断链接到来源，由分析师核对 [2]。过度依赖 AI 的观点 → 专业人员对最终文件和决策负全部责任 [1]。
**与相近工作流的区别：** AWF-0098 核保人定稿的信贷备忘录：一次起草由核保人修改，然后进入银行信贷审批。本工作流中，在人审阅之前，另一个 AI「挑战者」智能体先对草稿提出质疑，重新起草的循环在团队审阅下反复进行。交付物是股权投资委员会备忘录，而不是信贷备忘录。

## 公开实例

覆盖度（截至 2026-11-13）：**部分**：有第一手实例，但只覆盖流程的一部分，或检查点位置不同。收集与复核见 [Third collection pass](../../../../../research/2026-11-third-pass.md)。

- [Schroders Capital, virtual investment committee agent](https://schroders-capital.prezly.com/schroders-capital-expands-pioneering-ai-toolkit-with-virtual-investment-committee-agent) (2025-06-30)。私募市场机构自己的分析代理加挑战者投委会代理；每个版本都由人审阅。"GAiiA has already assisted with more than 40 investment cases"。*第一手：是；可信度：中。*
- [V7 Labs, Moderne Ventures](https://www.v7labs.com/news/moderne-ventures-accelerates-due-diligence-with-v7-go) (n.d.)。风险投资机构把数据室变成按模板生成、引用来源的备忘录，由合伙人核对。"makes the process go from weeks to a day"。*第一手：厂商；可信度：中。*
