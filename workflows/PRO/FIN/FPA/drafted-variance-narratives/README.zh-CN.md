# 预算差异说明初稿

**工具变体：** `pigment-analyst-agent-mcp`

## 背景

公司每个月都要把计划赚多少、花多少（预算）与实际发生的情况做比较。差距叫作差异。财务规划团队（FP&A，财务规划与分析）接着要用文字向高管解释每一处重要差异：收入低于计划是因为 X，招聘超前是因为 Y。写这些说明很慢，因为数字在计划系统里，原因在人的脑子里，同样的发现还要在每月最忙的时候针对不同读者重写一遍。在这里，智能体读取预算和实际数据，挑出关键变动，并按团队惯用的口吻起草说明。财务团队仍要核对每个数字，补上只有他们才知道的业务原因，并决定告诉高管什么，因为这份说明是管理层对业绩的陈述，团队要为此负责。

**术语：**
- **预算与实际（BvA）**：把计划数字与真实数字按科目和期间做对比。
- **差异**：预算与实际之间的差额。
- **差异说明（commentary）**：对差异的书面解释。
- **损益（P&L）**：某一期间的收入和成本报表。
- **人员编制（headcount）**：员工人数，以及与计划人数的对比。
- **现金流**：流入和流出的资金。
- **计划模型**：财务团队的计划系统，里面有预算、实际数据和备注。
- **公司口吻**：团队在说明里已经在用的措辞和格式。
- **MCP**：把智能体连接到外部系统的工具和数据的一种标准方式。

## 用智能体搭建

**形态：** `skill`。由一位财务团队成员负责月度说明，全程在对话中修改初稿，所以一个装有流程、公司口吻和格式的 skill 就够了。

**需要：** 一个能读取计划模型中预算与实际数据及其背景备注的连接（如果计划平台有 MCP 服务器就用它，否则用导出文件）；放在 skill 旁边的两三份过去的说明，作为公司口吻的范例；损益、人员编制和现金流的说明模板。连接应当是只读的：智能体没有理由向计划模型写入。

| 步骤 | 搭建方式 |
|---|---|
| 计划模型中的预算与实际数据 → 智能体通过 MCP 提取 | 通过连接计划模型的 MCP 连接器或导出文件，给 skill 提供当月的预算、实际数据和备注。 |
| 标出关键变动 + 趋势 | skill 让智能体计算每项差异并排序，列出最大的几项，以及近几个月的趋势。 |
| 按公司口吻起草说明 (损益、人员编制、现金流) | 智能体依据模板和范例说明起草每一部分，并写明所用的数字。 |
| 🛑 review (财务团队修改) | 见“检查点”。 |
| 整理高管摘要 → 🛑 handoff (管理层) | 修改完成后，skill 把已批准的说明浓缩成一份高管摘要文件。 |

**检查点：** `review`：skill 在初稿阶段结束时，把每份说明连同背后的数字一并呈现，然后停下；由财务团队成员更正、补充原因并批准。`handoff`：只有说明被标记为已批准之后，skill 才会整理摘要，而且它没有发邮件或发布的工具，所以由人把摘要交给管理层。

**与来源相比：** 唯一的来源和唯一的公开实例是同一篇未注明日期的厂商客户案例，所以无法给出它的时间。它讲的是一家计划平台厂商的分析功能，加上 Claude 通过该平台的 MCP 服务器读取数据。该厂商当前的文档（未注明日期；[MCP Server](https://kb.pigment.com/docs/mcp-server-1)，2026-11 查阅）称，启用其 AI 功能后即可使用 MCP 服务器，它沿用每位用户已有的访问权限，默认模式下的工具是只读的。上面的搭建方式用通用智能体加连接器或导出文件，代替了厂商的分析功能，所以它不会像那项功能那样标出关键变动。来源把节省的时间说成是公司自己的估计，这套搭建方式不作此声明。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 预算与实际数据及背景信息都存放在计划模型中。智能体（Claude）通过该平台的 Analyst Agent 和 MCP 服务器读取这些数据 [[1]](#sources)。
2. 智能体概括主要差异，找出值得注意的趋势，并标出关键变动 [[1]](#sources)。
3. 智能体按团队的口吻和格式，起草涵盖损益、人员编制和现金流的结构化说明初稿 [[1]](#sources)。
4. 🛑 **审阅**：财务团队成员结合判断和受众背景修改每份初稿。洞察的归属权仍在人手里 [[1]](#sources)。
5. 🛑 **接手**：说明经概括并整理后，交给高管审阅 [[1]](#sources)。

**产出：** 一份涵盖损益、人员编制和现金流的月度差异说明材料包，交付给高管。
**失败模式 → 防护：** 说明空泛或缺乏背景 → 由人结合判断和受众进行修改 [[1]](#sources)。
**与相近工作流的区别：** 对照底稿的月结（Workpaper-matched close，CLOSE，同一批次）产出对账后的底稿和会计分录。本工作流则为高管产出管理层说明。AWF-0006 受管控的查询（Governed query）回答临时的数据问题。
