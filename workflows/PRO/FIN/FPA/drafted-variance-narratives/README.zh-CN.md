# 预算差异说明初稿

**与相近工作流的区别：** 对照底稿的月结（Workpaper-matched close，CLOSE，同一批次）产出对账后的底稿和会计分录。本工作流则为高管产出管理层说明。AWF-0006 受管控的查询（Governed query）回答临时的数据问题。
**工具变体：** `pigment-analyst-agent-mcp`

## 步骤

1. 预算与实际数据及背景信息都存放在计划模型中。Claude 通过该平台的 Analyst Agent 和 MCP 服务器读取这些数据 [[1]](#sources)。
2. 智能体概括主要差异，找出值得注意的趋势，并标出关键变动 [[1]](#sources)。
3. 它按团队的口吻和格式，起草涵盖损益、人员编制和现金流的结构化说明初稿 [[1]](#sources)。
4. 🛑 **审阅**：财务团队成员结合判断和受众背景修改每份初稿。洞察的归属权仍在人手里 [[1]](#sources)。
5. 🛑 **接手**：说明经概括并整理后，交给高管审阅 [[1]](#sources)。

**产出：** 一份涵盖损益、人员编制和现金流的月度差异说明材料包，交付给高管。
**失败模式 → 防护：** 说明空泛或缺乏背景 → 由人结合判断和受众进行修改 [[1]](#sources)。
