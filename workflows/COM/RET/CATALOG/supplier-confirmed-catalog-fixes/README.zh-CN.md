# 供应商确认的商品纠错

**与相近工作流的区别：** 上文的 Instacart/Walmart 把疑问转给内部审核员。这里由外部供应商批准有风险的改动，并且直接就地编辑线上商品列表，因此检查点的负责人和产出都不同。
**工具变体：** `openai`

## 步骤

1. 利用网络信息和 Wayfair 的内部定义，生成一份说明每个标签含义的指南 [[1]](#sources)。
2. 模型对照指南审查商品信息，并分配标签（颜色、材质、尺寸） [[1]](#sources)。
3. 高置信度：直接更新内容并通知供应商。🛑 **操作**：低置信度或高风险的改动需先经供应商确认 [[1]](#sources)。
4. 🛑 **抽检**：员工在结构化审计中检查商品样本 [[1]](#sources)。

**产出：** 已纠错的线上商品列表；影响通过 A/B 测试衡量。
**失败模式 → 防护：** 错误地改动供应商内容 → 按置信度和风险分流到供应商确认。

## 公开实例

覆盖度（截至 2026-11-06）：**薄弱**：只有匿名、与厂商相关或由记者转述的说法。收集与复核见 [Second collection pass](../../../../../research/2026-11-second-pass.md)。

- [OpenAI, Wayfair](https://openai.com/index/wayfair/) (2026-09-25)。处理了超过 100 万件商品；A/B 测试显示展示量和点击量增加。"has processed more than 1 million products"。*第一手：厂商；可信度：中。*
