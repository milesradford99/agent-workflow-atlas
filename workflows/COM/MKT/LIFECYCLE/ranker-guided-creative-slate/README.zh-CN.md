# 排序器引导的创意候选集

**工具变体：** `llm` · `thompson-sampling` · `bradley-terry-ranker`

## 背景

营销活动团队需要在多个文案变体中选择，但生成更多文本并不能说明真实客户会回应哪条消息。用以往实验训练的模型可以帮助筛选候选，新一轮受控测试才提供针对当前活动的证据。本工作流用排序器引导有限修改，再把经过审阅的候选集送入自适应实验。智能体可以起草方案并整理证据。文案和实验触达仍由人批准，因为客户会收到活动消息，而离线评分不是可靠的上线决定。

**术语：**
- **创意 / 候选集（creative / slate）**：被测试的消息，以及准许进入测试的候选集合。
- **LLM / 排序器 / Bradley–Terry**：文本生成模型、学习排序的预测器，以及成对比较模型。
- **A/B 测试 / arm**：受控比较，以及其中的一个候选。
- **多臂赌博机 / Thompson 采样**：根据结果调整分配的实验，以及一种概率分配方法。
- **代理指标 / 过拟合**：间接目标，以及优化它却无法改善真实结果的情况。

## 用智能体搭建

**形态：** `platform`。核心评分需要经过训练的活动预测模型和受控的线上实验。通用智能体可以用 `project` 协调准备工作，但不能用自己的判断替代这些组件。

**需要：** 人工种子文案、历史随机测试数据和已验证排序器；生成与评分接口；获批的受众规则和实验平台；可审阅的活动工作区。收件人标识不进入起草上下文。不给智能体发送、上线或流量分配权。

| 步骤 | 搭建方式 |
|---|---|
| 人工种子 → 变体 → 排序 | Skill 起草候选；脚本调用已训练排序器，记录分数与模型版本。 |
| 一轮改进 → 合并 + 重新排序 → 候选集 | Skill 完成有次数限制的修改；脚本去重并重新评分。Hook 阻止超出获批流程继续优化代理指标。 |
| 🛑 review → 自适应赌博机测试 | 智能体准备文案、证据和测试配置。由人在专用平台启动获批实验。 |
| 选出胜者 | 实验平台收集真实回应，执行其统计选择流程；Skill 汇报结果及局限。 |

**检查点：** `review`：活动负责人看到完整候选集、事实来源、排序器版本、拟用受众及实验配置。智能体没有上线或分配工具；由人批准并启动线上测试。排序器的最高分不能绕过测试，也不能授权发送。

**与来源相比：** 来源出自 2026-07，摘要和论文全文均已于 2026-11 打开。针对更新实例及所列方法的检索，截至 2026-11 未找到更新实例。论文中的排序器由历史实验训练，并不能与通用智能体的点评互换。当前 Skills 和 Hooks 可以组织有次数限制的生成和审阅，模型训练与线上分配仍留在专用系统中。保留离线筛选与实测线上回应的区别；文案更好读或代理分数更高，都不能证明活动更有效。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 活动团队从人工撰写的种子创意出发，用于一次促销邮件或推送活动 [[1]](#sources)。
2. 冻结的生成模型提出变体；用历史上同一活动内 A/B 测试训练出的预测模型（Bradley-Terry 式）对它们排序 [[1]](#sources)。
3. 系统把排序结果回传给 LLM，只做一步改进（更深的轮次会过拟合代理指标而退步）；把所有候选合并并重新排序，形成测试候选集 [[1]](#sources)。
4. 🛑 **审阅**：候选集在上线前经过人工审阅 [[1]](#sources)。
5. 实验系统在线上自适应实验中部署候选集：首批均等分配，之后的批次把流量转向表现强的变体（Thompson 采样） [[1]](#sources)。
6. 实验系统依据真实用户反馈选出胜者；不要直接部署排序器离线选出的第一名（在主要研究中它在 50 个里只排第 43） [[1]](#sources)。

**产出：** 该活动中表现最好的文案创意，由线上自适应测试选出；测试数据回流到排序器，用于之后的活动。
**失败模式 → 防护：** 把离线排序器当作部署规则（它选的第一名排在第 43） → 只用它来构建高召回的候选集，由线上测试做选择。针对代理指标过度改进 → 改进一轮即止。文案不符合品牌调性或有误 → 上线前人工审阅候选集。

**与相近工作流的区别：** 最接近的是 AWF-0054 有护栏的营销活动搭建（搭建一个活动，带计划 + 导出审批和简单的 A/B 测试）和 AWF-0178 有护栏的一对一决策（对每位客户挑选文案/渠道/时机，对照留存组）。本工作流为一次发送生成并筛选大量创意变体，只设一个候选集审阅检查点，并通过自适应实验来选择。交付物（胜出创意）和检查点（候选集审阅）与二者都不同。
