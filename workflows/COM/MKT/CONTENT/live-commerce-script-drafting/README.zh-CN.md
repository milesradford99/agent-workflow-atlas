# 直播口播稿起草

**与相近工作流的区别：** 最接近的是 AWF-0018 聚类-简报-起草式内容：那是产出带排名跟踪的 SEO 文章。本工作流则根据商家条款和种草文案，为每个 SKU 产出直播带货的口语化脚本，以法务合规审核和主播个性化调整为检查点。交付物和检查点都不同。
**工具变体：** `deepseek` · `doubao` · `douyin-jichuang`

## 步骤

1. 录入商家的商品信息：名称、零售价、机制、直播价 [[1]](#sources)。
2. 让智能体从小红书等种草平台收集 KOL/KOC 对同一商品的介绍和评论 [[1]](#sources)。
3. 提示模型把商品事实和收集到的文案重新组合成口播话术：切入点、痛点、卖点；预先设定的规则过滤敏感词、违规词以及夸大或虚假的宣传（每条脚本约 40-60 秒） [[1]](#sources)。
4. 🛑 **审阅**：法务逐条检查每份口播稿是否合规 [[1]](#sources)。（另外，同一平台还让 AI 预审商家资质和品牌授权，并输出结构化的审核意见 [[2]](#sources)。）
5. 🛑 **审阅**：主播在开播前把脚本调整成自己的风格 [[1]](#sources)。
6. 脚本进入直播；先拆解热销视频，同样的逻辑也复用于短视频脚本 [[1]](#sources)。

**产出：** 每个商品一份经合规检查的口播稿，交给主播用于直播。
**失败模式 → 防护：** 文案太书面、不口语 → 换模型（豆包换成 DeepSeek），输出更口语化 [1]。网上的文案把违规或夸大内容带进脚本 → 规则过滤加法务审核 [1]。

## 公开实例

覆盖度（截至 2026-11-13）：**薄弱**：只有匿名、与厂商相关或记者转述的说法。收集与复核见 [Third collection pass](../../../../../research/2026-11-third-pass.md)。

- [新榜 / 虎嗅, interview with 交个朋友 VP 刘亚平](https://www.huxiu.com/article/4263055.html) (2025-04-21)。AI 口播稿嵌入交个朋友的直播工作流；法务审核后再由主播修改。"成功将单条口播稿的时间从人工的20～40分钟缩短至2分钟，单人力单日输出量也从20条提升至100+条"。*第一手：访谈；可信度：高。*
