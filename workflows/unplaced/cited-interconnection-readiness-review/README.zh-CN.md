# 带引注的并网申请完备性审查

**与相近工作流的区别：** 最接近的是 AWF-0151（首轮提交物审查：施工提交物对照规格，先由项目经理审阅，再由记录审阅人签发）。同样是对照规则检查的模式，但本工作流对照费率规则并行处理整个监管队列的一批申请，交付物是每份申请的带引注完备性报告，并且只有电网运营商的最终判定是检查点（没有逐条的项目经理修改环节）。所属领域不同：电网并网。
**工具变体：** `tapestry-hyperq`

## 步骤

1. 把 PJM 的费率规则、用户手册以及员工过往评定申请的方式提炼成一套指令集；提取和合规任务通过编排层分配给不同的智能体 [[1]](#sources)。
2. 本轮周期内的每份申请并行处理：智能体摄取 PDF、地图和法律文件，并对照费率要求执行场地控制的申请完备性审查 [[1]](#sources)。
3. 输出是每份申请的完备性报告，带有精确到页、条款或坐标的引注，并标出缺陷 [[1]](#sources)。
4. 🛑 **签发**：PJM 的专家工程师借助报告作出最终合规判定 [[1]](#sources)。

**产出：** 每份申请一份有引注支撑的完备性报告，交给电网运营商的工程师；被判定完备的项目进入研究阶段。
**失败模式 → 防护：** 监管队列中的黑箱判断 → 每项评估都链接到来源页码/条款，判定权留在工程师手中 [1]。复杂申请的运行时间长尾 → 跟踪 p95（28 分钟）[1]。
