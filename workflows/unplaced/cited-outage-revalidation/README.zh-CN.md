# 带引用的停运复核

**与相近工作流的区别：** AWF-0213（带引用的并网就绪审查，cited interconnection readiness review）是一次性批量对照电价规则（tariff）检查新的并网申请，最后由工程师做出合规判定。本工作流在固定的时间节点上，每天复核每一个在途的设施停运申请，产出控制室人员据以行动的运行报告。触发方式、节奏、交付物和审阅人都不同。
**工具变体：** `oati-genie`

## 步骤

1. 在计划的研究检查点（如 D+21、D+2、D+1）或按需触发。CAISO 电网每天收到 500 多个新的发电停运申请和 200 多个新的输电停运申请 [[1]](#sources)。
2. 一个编排器协调各专门智能体。工作流智能体（Workflow agent）对全部申请运行计划内的复核。它利用 OASIS、市场系统和规程数据，复核建模、市场影响、历史停运设置、运行规程，以及自由文本停运备注中的异常 [[1]](#sources)[[2]](#sources)。
3. 相似度检索智能体按设备、位置和规程，把每个申请与历史停运记录比对。关键词智能体对照 CAISO 的运行词典阅读自由文本备注，并标出不一致之处 [[2]](#sources)。
4. 报告智能体生成每晚的分析报告，含异常标记和建议。每条建议都带有可追溯的推理、来源引用、先例和置信度 [[1]](#sources)。
5. 🛑 **审阅**：输电、可靠性和发电方面的运行人员和工程师审阅发现，并亲自完成更正。系统只提供参考意见，不能采取任何可靠性操作 [[1]](#sources)。
6. 用户通过内置的反馈功能提交反馈，反馈回到开发周期。对话有追踪记录，访问按角色控制 [[1]](#sources)。

**产出：** 一份每晚的停运复核报告，在审阅人开始一天工作前就准备好，另有对规程和单线图问题的带引用回答。所有更正由运行人员在停运管理系统中完成。
**失败模式 → 防护：** 意图路由错误会让每个回答都显得不对 → 把意图路由视为关键环节。团队没有参与设计的遗留数据结构 → 被点明为难点。幻觉式建议 → 每个智能体先单独验证再集成，每条发现都附引用，且不做任何自主的电网操作（符合 NERC/CIP）。运行人员信任度低 → 培训和反馈循环。

## 公开实例

覆盖度（截至 2026-11-13）：**充分**：有详细的第一手实例，与流程的大部分环节一致。收集与复核见 [Fourth collection pass](../../../research/2026-11-fourth-pass.md)。

- [California ISO, Deploying Agentic AI into Facility Outage Management](https://www.nationalacademies.org/cdn/materials/a3191bca-d63d-473b-ae9e-a98add3301c6) (2026; exact date not on page)。Genie 已在生产环境扩大范围内测：每晚复核次日的停运申请；由运行人员决定。"< 8 min to analyze 500+ next-day outage requests, ready before reviewers start the day"。*第一手：是；可信度：高。*
