# Unplaced workflows

Workflows that don't fit any class in [taxonomy.yaml](../../taxonomy.yaml) go here, one folder each (`unplaced/<name>/README.md`). Set `kingdom`, `phylum` and `class` to your best guess, or `null`, and say in the README why nothing fit.

Once three unplaced workflows share a likely home, a maintainer opens a new class or phylum and moves them (TAXONOMY.md rule 2). Unplaced workflows can't be `accepted`.
