# 分阶段预览的 CAD 建模

**工具变体：** `cadquery` · `trimesh-pyrender`

## 背景

3D 打印是把熔化的塑料一层层铺起来做出零件，所以数字模型不仅要满足功能，还要迁就这个过程：壁要够厚，悬垂不能超过打印机能撑住的角度，底面要有一块平面抓住打印床。制作者用 CAD 设计这类零件，而一次性的支架或手机支架，尺寸通常由几个数决定——充电盘直径、线缆粗细、壁厚——反复微调直到装得上。参数化模型把这些数保留成具名变量，下一次改版只需改一个数，不必重做。手工做这件事慢在两个地方：每改一次都要重建模型再重新看一遍；而错误（比如按键做成凹的）往往要拿到实物才看得清。在这里，智能体把模型写成脚本，渲染出图，先按打印约束自查再给人看；制作者在每个阶段看预览，用大白话说哪里不对，最后切片判断能不能打。这两个判断仍归制作者：零件装不装得上实物，走刀路径出来能不能打，是一张图和一段脚本都定不了的。

**术语：**
- **参数化 CAD**：用带名字的数（“壁厚 = 1.2 mm”）建模，改一处即可，不必重建。
- **CadQuery**：用 Python 代码构建实体模型的库；模型本身就是一段可版本管理、可 diff 的脚本。
- **STL**：切片软件读取的三角网格，只保留形状，不含参数。
- **水密（watertight）**：网格没有破洞，切片软件才能分清内外。
- **切片软件（slicer）**：把网格转成打印机指令的程序，也是打印问题最先暴露的地方。
- **悬垂（overhang）**：悬在空处向外伸的面；角度太陡就需要支撑材料。
- **粘床（bed adhesion）**：第一层贴在打印床上的牢靠程度；翘边或脱落就整件报废。
- **布尔运算（boolean）**：用另一个实体去合并或切除，孔和槽就是这么做的。

## 用智能体搭建

**形态：** `skill`。一位制作者、一个零件、在每个阶段带一次预览的对话：流程和它的清单放进一个 skill，旁边配两个脚本即可。

**需要：** 装好 CadQuery 的 Python 环境（CadQuery 需要 Python 3.10 到 3.12），以及一个无头渲染库，例如 trimesh 配 pyrender，这样没有屏幕也能出预览图；一个切片软件，由制作者使用；零件要装配的真实尺寸，来自制作者或供应商公布的图纸；一个存放脚本、STL 和渲染图的目录。不需要接触打印机：打印由制作者完成。

| 步骤 | 搭建方式 |
|---|---|
| 收集需求 + 调研尺寸 | Skill 的第一条指令：问清零件要装什么，再去读供应商或标准页面拿到配合尺寸，并把它们写成具名变量。 |
| 各阶段：CadQuery 脚本 → STL → 四视图渲染 ⟲ 清单自查 | Skill 旁边的脚本负责跑模型、导出 STL 并渲染四视图；打印清单是一份参考文件，智能体对着自己的渲染图逐条核对，未通过就继续循环。 |
| 🛑 review（预览） | Skill 在每个阶段结束时停下，展示渲染图以及产生它的参数；制作者回复后才进入下一阶段。 |
| 参数表 + STL | Skill 的收尾步骤：把制作者可能改动的每个尺寸、变量名和当前值，写在 STL 旁边。 |
| 切片 | 由制作者切片；智能体从不驱动打印机。 |
| 🛑 review（切片软件/打印适配） | 切片截图回到对话里；智能体据此判断是哪个参数的问题，改参数并重新渲染。 |

**检查点：** `review`：两道关卡都是 Skill 停下等待。每个阶段结束它只给出渲染图，制作者答复之前不写下一阶段的代码；打印之前它给出参数表和 STL，切片这一步留在制作者手上，所以打不出来的零件无法经由智能体送到机器上。

## 步骤

*以下按来源所述。*

1. 在对话中收集需求，然后调研零件必须适配的真实尺寸。在 MagSafe 支架这个实例中，这指的是充电盘尺寸、线圈位置和线缆直径；在手机壳实例中，则是 Apple 的配件设计指南 [[1]](#sources)。
2. 分三个可视化阶段搭建：先是基础形体，再是特征，最后是收尾清理。绝不直接跳到成品模型，因为基础形体一旦错了，细节工作就白做了 [[1]](#sources)。
3. 每个阶段都编写参数化的 CadQuery 脚本，运行后得到 STL，再用 trimesh/pyrender 渲染四视图预览。智能体会查看自己的渲染图 [[1]](#sources)。
4. 对照设计清单自查每一张预览：是否符合需求、特征是否可见、底面是否平整以便贴合打印床、悬垂角是否小于 45 度、壁厚是否大于 1.2mm。在给人看之前先迭代 [[1]](#sources)。
5. 🛑 **审阅**：每个阶段结束时，制作者查看预览并给出修改意见，例如“再高 5mm”或“线缆孔没有打通”。然后才进入下一阶段 [[1]](#sources)。
6. 交付 STL，以及一张包含所有关键参数的表，方便快速调整 [[1]](#sources)。
7. 🛑 **审阅**：制作者对零件做切片，并把切片软件的截图作为反馈发回来。这样能在浪费耗材之前发现结构和间隙问题 [[1]](#sources)。

**产出：** 一份参数化的 CadQuery 脚本和 STL，附参数表，可直接切片打印。之后的改动通过编辑参数完成。
**失败模式 → 防护：** 布尔运算静默失败、壳体太薄无法打印、特征切反了方向（按键凹进去而不是凸出来）→ 每张预览的清单自查，加上每个阶段的人工预览关卡。几何不稳定或无法使用（支架会倒）→ 真实的切片软件反馈，加上由人判断实际使用情况。
**与相近工作流的区别：** 目录中暂无相近者。AWF-0007 和 AWF-0008 产出的是 UI 代码，而不是实体几何。
