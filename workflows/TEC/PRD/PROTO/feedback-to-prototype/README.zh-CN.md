# 从用户反馈到原型

## 步骤

1. 把工单、通话记录和 NPS 原话聚类成主题，每个主题附计数和带来源链接的引述。
2. 🛑 **计划**：产品经理选定要解决的问题。
3. 起草 PRD：问题、用户、非目标、指标、用户故事、边界情况。由一个评审者做红队质疑（“工程团队会反对什么？”）。
4. 根据 PRD 和设计令牌做 2–3 个原型方案（v0、Lovable、Bolt、Figma Make、Claude artifacts）。
5. 迭代。
6. 🛑 **审阅**：设计评审。
7. 进行 5 次用户测试，并把转写内容回流到第 1 步。

**产出：** PRD 和原型成为 AWF-0001 或 AWF-0008 的输入。
