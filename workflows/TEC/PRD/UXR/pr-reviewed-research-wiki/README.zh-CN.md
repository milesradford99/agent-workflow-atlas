# 经 PR 审阅的研究维基

**工具变体：** `microsoft-teams` · `git-pull-requests`

## 背景

研究团队需要跨多场访谈保存发现，使后续决策不只依赖最近一份报告。共享维基可以积累证据，但自动摘要可能漏掉参与者的背景，或者覆盖早先的解释。本工作流从每场新访谈更新维基，并把变化作为可审阅的差异展示出来。智能体定时获取和整理材料。研究员在合并前检查遗漏和解释，因为其他人会把维基作为决策依据。

**术语：**
- **维基 / LLM wiki**：相互关联的研究笔记，供人和语言模型工具共同使用。
- **PR / merge / diff**：提议的版本化更新、接受更新，以及改变的文本。
- **参与者分群**：具有相关共同背景的群体，例如新用户与有经验的用户。
- **文字稿 / 录像工具**：写下来的语音内容，以及从访谈录像提取证据的工具。

## 用智能体搭建

**形态：** `service`。每日定时启动更新，研究员收到逐项的修改提案进行审阅。

**需要：** 获批的访谈文字稿访问权限及已有录像处理工具；研究简报与参与者分群；有版本控制的维基；仅能创建分支与 PR 的代码托管 MCP server (connector) 工具；已处理访谈台账。录像及个人数据留在批准的存储中，不授予合并或公开发布权限。

| 步骤 | 搭建方式 |
|---|---|
| 每天：文字稿 → 处理录像 | 定时 `claude -p` (headless) 运行调用 Skill；限定范围的 MCP server (connector) 工具读取获授权访谈及已有视频工具的输出。 |
| 整合发现进维基 → 开 PR | Skill 读取研究背景，把每项新增内容链接到访谈证据并写入分支。记录已处理访谈编号，避免重复更新。 |
| 🛑 review → 合并 | 服务创建 PR，附 diff、来源链接和不确定的解释。研究员修正并执行合并。 |

**检查点：** `review`：研究员收到维基 diff、访谈引用和标记的冲突，各参与者分群保持分开。智能体不能合并或发布；已有分支保护要求研究员批准。录像提取失败或不完整时，明确记录缺口，不编造观察。

**与来源相比：** 来源出自 2026-09，已于 2026-11 打开。针对更新实例及所列工具的检索，截至 2026-11 未找到更新实例。无界面 Skill 可以协调每日流程，不必重建一组有名称的智能体。来源没有说明视频工具是什么，也没有提供可复用实现；本设计假设已经存在获批处理工具，不宣称文字智能体能替代视频或转录处理。持久的来源链接与研究员 PR 审阅仍然必需。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 研究员把研究的发现保存在受版本控制的 "LLM wiki" 中，而不是一份报告里；研究员会 "constantly tweaking and adjusting" 它 [[1]](#sources)。
2. 一串智能体每天循环运行：从 Teams 获取访谈文字稿，让录像经过团队的视频工具处理，把结果整合进维基 [[1]](#sources)。
3. 这串智能体带着改动开一个 pull request [[1]](#sources)。
4. 🛑 **审阅**：研究员在合并之前审阅 PR（"oh, it missed this, it missed that"）[[1]](#sources)。
5. 同一团队还会在分析之前先组装好上下文（简报、项目笔记、参与者分群），避免各分群被一概而论 [[1]](#sources)。

**产出：** 一个持续更新的研究维基，每次改动都由研究员合并；取代一次性的报告。
**失败模式 → 防护：** 智能体漏掉发现 → 合并前做 PR 审阅 [1]。分析抹平了参与者分群之间的差异 → 纳入简报和分群上下文 [1]。

**与相近工作流的区别：** AWF-0061 引文核验式综合（Quote-verified synthesis）产出一次性报告，带主题核验和研究员签发；AWF-0120 负责开展访谈。这里由每日运行的智能体链更新一个长期维护的研究维基，检查点是每次更新的 PR 审阅：产出物和节奏都不同。

## 公开实例

覆盖度（截至 2026-11-13）：**薄弱**：只有匿名的、与厂商相关的或记者转述的说法。收集与复核见 [Third collection pass](../../../../../research/2026-11-third-pass.md)。

- [Microsoft Design, Rebuilding research from the ground up](https://microsoft.design/articles/rebuilding-research-from-the-ground-up/) (2026-09-10)。Core AI 的首席 UX 研究员运行一条每日的智能体链，写入维基，并经 PR 审阅。"Report writing that once took a week and a half now takes one to three days"。*第一手：访谈；可信度：中。*
