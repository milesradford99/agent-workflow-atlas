# 农技员中转的农业咨询

**与相近工作流的区别：** 最接近的是 AWF-0154（按地块登记的农艺建议）：它按整个季节制定针对具体地块的养分方案，由农户核对地块并交给技术员接手。本工作流是针对任意作物或主题的按需问答，没有地块模型，人工检查点是农技推广员在每条答复到达农户之前先审阅（辅助，而不是分段）。
**工具变体：** `farmer-chat`

## 步骤

1. 用培训视频转写稿、带标注的呼叫中心日志和作物研究简报构建一个精选知识库；印度农业部审定其中所有文档 [[2]](#sources)。
2. 农技推广员（或带头农户）通过文字、语音或作物照片提问；助手从知识库检索（RAG），并用当地语言作答，同时提供天气和病害诊断服务 [[1]](#sources)[[2]](#sources)。
3. 🛑 **审阅**：在最初的推广阶段，聊天机器人是作为农技推广员的助手部署的，而不是直接面向农户，因此推广员会先审阅建议再转达 [[2]](#sources)。
4. 未能回答的提问由 LLM 分为超出语境、收录不足和内容缺失三类；内容缺失的缺口推动知识库补充 [[1]](#sources)。

**产出：** 由农技推广员转达给农户的咨询答复；以及未能回答的提问日志，用于更新知识库。
**失败模式 → 防护：** 聊天机器人给农户错误建议 → 精选知识库，并以农技推广员作为审阅环节 [2]。知识缺口：66% 的未答提问属于内容缺失 → 缺口归类和知识库更新 [1]。

## 公开实例

覆盖度（截至 2026-11-13）：**充分**：有详细的第一手实例，与流程的大部分环节一致。收集与复核见 [Third collection pass](../../../../../research/2026-11-third-pass.md)。

- [Digital Green, Farmer.Chat (arXiv 2409.08916)](https://arxiv.org/abs/2409.08916) (2024-10-08)。在肯尼亚、印度、埃塞俄比亚和尼日利亚部署；用户包括农技推广员、带头农户和农户。"Deployed in four countries, Farmer.Chat has engaged over 15,000 farmers and answered over 300,000 queries."。*第一手：是；可信度：高。*
- [OpenAI, Digital Green](https://openai.com/index/digital-green/) (n.d.)。CEO 解释先从农技推广员入手的推广方式，相当于一个人工审阅环节。"As of January 1, 2024, over 4,500 extension agents are using Farmer.Chat across both Kenya and India."。*第一手：厂商；可信度：中。*
