# 模型分流的记录公开审查

**工具变体：** `state-dept-ips-declass`

## 背景

政府会把敏感记录定为涉密，过了规定的期限之后，审查人要判断每一份记录现在能否向公众公开，还是必须继续保密。像外交电报（外交部与驻外使馆之间的正式往来电文）这样数量动辄几十万份的记录，靠人逐份阅读根本来不及。这里由模型把每份记录分为可能公开、可能豁免（受某项法律规定保护）或不确定，审查人只读不确定的那些，并抽查其余部分。不确定的记录仍由人来裁定，模型的判断也仍由人来抽检：因为不该公开的内容一旦公开就无法收回，而公开的法律责任在机构。

**术语：**
- **解密（declassification）**：解除记录的涉密状态，使其可以公开。
- **豁免（exempt）**：受某项具体法律规定保护而不予公开，记录继续保密或进入进一步审查。
- **FOIA 阅览室**：机构发布依据《信息自由法》（FOIA）已公开记录的公共网站。
- **电报（cable）**：正式的外交电文，在这里是被审查的记录类型。
- **标注（labels）**：过往的人工决定（公开或豁免），模型据此训练。
- **质检抽样（QC sampling）**：由人复查模型有把握的判断中的一部分，看它有没有错。
- **主题漂移**：局势变化会改变什么算敏感，旧的决定就不再是好的依据。
- **NARA**：美国国家档案和记录管理局，接收继续保密的记录。

## 用智能体搭建

**形态：** `service`。这项工作是对大型档案分批运行，人只看到不确定的记录和抽检样本，所以它是由调度程序启动的运行，而不是一场对话。通用智能体能否达到来源所用训练模型的水平，来源没有说明：这里的搭建用依据书面指引逐份阅读记录的智能体取代了它。

**需要：** 本批记录的副本，放在经批准可处理涉密或敏感材料的环境中，不能放在通用环境里；过往审查人的决定及理由，整理成一份示例文件；书面的审查指引和豁免规则，作为参考文件；对记录所在审查系统的读取权限，写入权限只限“预测”字段；一个位于对话之外的存储，记录每份记录的判断、审查人的更正和抽检结果；两个队列，一个放不确定的记录，一个放抽检样本。

| 步骤 | 搭建方式 |
|---|---|
| 过往审查人的决定 → 训练模型 | 不做训练。由脚本挑出同一记录类型、同一主题的若干过往决定，skill 把它们作为示例摆给智能体看。若已有训练好的分类器，就当作脚本调用。 |
| 每份记录：判定 解密 \| 豁免 \| 不确定 | 由动态工作流把每份记录交给子智能体，返回判断、所依据的规则和一句话理由。两个智能体意见不一，或没有规则明确适用的记录，判为不确定。 |
| 不确定：🛑 handoff (人工审查人) | 记录连同两个智能体给出的理由进入不确定队列。 |
| 🛑 sample (对模型判断做质检) | 固定比例的有把握的判断被复制到抽检队列。审查人的结论写入存储。 |
| 把决定载入审查系统 → 发布到 FOIA 阅览室 | 由连接器把预测的判断写入审查系统。发布由工作人员完成。 |
| 针对主题漂移重新训练 | 审查人的更正被加入示例文件。审查人推翻智能体判断的比率保存在存储中，由人决定何时修订指引。 |

**检查点：** `handoff`：不确定队列是这些记录往下走的唯一途径，智能体没有办法把其中任何一份标记为已公开。`sample`：样本由运行中的脚本抽取，不由智能体挑选，结果用于计算推翻比率。智能体没有发布工具，权限规则拒绝写入阅览室或任何公开字段，所以除非工作人员动手，否则什么都不会公开。

**与来源相比：** 来源的时间为 2024-05 至 2024-06。2026-11 的检索找到一篇更新的报道：[Federal News Network](https://federalnewsnetwork.com/federal-insights/2026/05/agencies-look-to-ai-automation-amid-growth-in-digital-records/)（2026-05），其中国务院一位官员说已在用 AI 工具做解密审查，并预计电报解密的工作量将增长到五倍；报道没有描述具体步骤。来源 1 的 PDF 能打开但没有得到可读的文本，所以其中的数字没有在这里重读。来源使用的是依据过往决定训练的、把记录分成三组的模型；这里的搭建用的是依据书面指引逐份阅读记录的通用智能体，来源没有测试过这一点，也没有说明通用智能体做这件事效果如何。这里不作任何效果上的断言。

*以上是依据本条目的步骤和截至 2026-11 的工具文档做出的设计，不是已报道的实例。*

## 步骤

*以下按来源所述。*

1. 团队选定一种格式统一的记录（eRecords 中的外交电报），其过往的人工解密决定可以充当标注 [[1]](#sources)。
2. 团队用这些决定训练模型（解密与豁免解密）。试点中的训练数据是 1995–96 年的电报决定，模型则用于处理 1997 年的电报 [[1]](#sources)[[2]](#sources)。
3. 模型把每份电报判定为可能解密、可能豁免或需要人工审查 [[2]](#sources)。
4. 🛑 **接手**：模型拿不准的电报交给人工审查人 [[1]](#sources)。
5. 🛑 **抽检**：人工对模型输出做质量检查，并按需重新标注训练数据 [[1]](#sources)。
6. 团队把模型预测载入审查系统，然后在 FOIA 阅览室主动发布已解密的电报（案号 S-2023-00002，每月发布）[[1]](#sources)。
7. 团队重新训练并监测主题漂移。随着世界局势变化，敏感内容也在变，工作人员要持续审阅训练数据 [[1]](#sources)[[2]](#sources)。

**产出：** 每月发布到国务院 FOIA 阅览室的已解密历史记录。豁免的记录转交 NARA 或进一步审查。
**失败模式 → 防护：** 主题漂移使过往决定不再适合作为依据 → 由人关注漂移并重新训练。判断不透明 → 准备好解释 AI 如何得出结果。FOIA 数据杂乱，分散在 3 个系统中 → 先做好数据准备 [[1]](#sources)。置信度阈值未公开 [[2]](#sources)。
**与相近工作流的区别：** AWF-0005 告警充实与裁定（Alert enrich and adjudicate，SECOPS）同样按置信度分流，但它裁定的是安全告警。这里的产出是依据解密/FOIA 规定经法律审查后公开的政府记录，并带有质检抽样。没有相近的工作流。
