# Input: the research brief

The brief as given to the agent, unedited.

I am building an open-source repository to catalog how people across all professions use AI Agents in real-world production workflows (e.g., coding, design, academic research, novel/scriptwriting, industrialized short-drama production, etc.).
Before designing the repository architecture, I need you to conduct Phase 1: Deep Research & Taxonomy Design.
1. Objective Map out how humans are currently using AI Agents to execute actual work, moving beyond simple chat prompts into multi-step, agentic Standard Operating Procedures (SOPs).
2. Deliverables Produce a comprehensive research report containing:

* A Taxonomy & Indexing System: A logical, scalable classification framework (e.g., by industry, role, task complexity, or agent pattern) that makes it easy to index and retrieve any workflow.
* Cross-Industry Landscape: Coverage of diverse domains—specifically including software engineering, product design, academic writing, fiction/screenwriting, industrialized short-drama (短剧) production, and other high-adoption fields.
* Concrete SOP Breakdowns: For each major category, document 1–2 representative, real-world agentic workflows. Detail the exact loop: Input -> Agent Roles/Tools -> Step-by-step Execution -> Human-in-the-loop Checkpoints -> Final Output.

3. Verification Criteria (How I will evaluate your output)

* Actionability over Generality: Workflows must describe concrete, reproducible SOPs and toolchains, not vague statements like "use AI to brainstorm."
* Structural Clarity: The taxonomy must be mutually exclusive and collectively exhaustive (MECE) enough to serve as the directory and tagging structure for a GitHub repo.
* Signal-to-Noise Ratio: Zero fluff. Focus purely on how work actually gets done with agents today.

Complete this Phase 1 research report first. Once I review and verify it, we will move on to Phase 2 (Repository Architecture & Contribution Templates).
